# 성경 낱말 사전 저작 규칙 (scripture_words)

개역한글 본문에 나오는 **낱말 하나**(기름 뿔·나룻배·보자기에 싸이다·대문짝에 그적거리다)가 무엇이고 어떻게 생겼는지를
구절 근거로 적는다. 정본은 `data/scripture_words/words.json`, 검사기는 `backend/scripts/validate_scripture_words.py`.
용어 정의는 `.forge/CONTEXT.md` 「성경 낱말 사전」.

## 0. 목적

항목 하나에 독자가 둘이다.

- **앱 독자**: 구절을 읽다 낱말을 누르면 보는 **뜻풀이**(`meaning`). 어린아이도 알아듣게 쓴다.
- **장면 명세 저작자**: 그 낱말을 그림 문구로 옮길 **모양 설명**(`look`)과, 그려진 그림을 재는 **판정 기준**(`criteria`).

한 번 찾은 낱말은 장면이 바뀌어도 다시 찾지 않고 이 사전에서 가져온다(베들레헴과 기혼의 「기름 뿔」은 같은 항목).

## 1. 위치

- `data/scripture_words/words.json` — `{ "version": 1, "words": [항목, …] }`
- `data/scripture_words/AUTHORING.md` — 이 문서
- `backend/scripts/validate_scripture_words.py` — 검사기(`--selftest`는 깨뜨린 사본으로 음성 대조)

## 2. 스키마

```json
{
  "id": "oil-horn",
  "word": "기름 뿔",
  "forms": ["기름 뿔을", "기름을 뿔에"],
  "kjv": "horn of oil",
  "refs": ["삼상 16:13", "삼상 16:1", "왕상 1:39"],
  "meaning": { "ko": "기름을 담아 두는 짐승의 뿔이에요. 왕을 세울 때 그 머리에 기름을 부었어요.",
               "grounds": "[직접] 삼상 16:1 「기름을 뿔에 채워」 · 삼상 16:13 「기름 뿔을 취하여 … 부었더니」" },
  "look": {
    "L1": { "ko": "기름 뿔", "en": "an animal horn of oil" },
    "L2": { "ko": "…", "en": "…" },
    "L3": { "ko": "…", "en": "…" },
    "grounds": "[추론] …"
  },
  "criteria": {
    "ko": "판정용 자세한 설명(길이 제한 없음)",
    "features": [ { "q": "뿔이 한쪽으로 굽었나?", "grounds": "[추론] …" } ]
  },
  "verified_level": { "level": "L2", "status": "확정", "with": [] }
}
```

| 칸 | 필수 | 뜻 |
|---|---|---|
| `id` | ✓ | 영문 kebab(`oil-horn`). 사전 안에서 하나뿐 |
| `word` | ✓ | 표제어, 개역한글 기본형. **낱말 묶음**일 수 있다(§3 규칙 8) |
| `forms` | ✓ | 본문에 실제로 나온 꼴 목록(활용·띄어쓰기 그대로) |
| `kjv` | ✓ | KJV 대응어 |
| `refs` | ✓ | 그 낱말이 나오는 구절 참조(개역 약어 `삼상 16:13`, 범위 `삼하 19:15-18` 허용). 시험 장면 구절 하나 이상 + 같은 낱말 용례 구절 |
| `drawable` |  | 기본 `true`. 그릴 수 없는 낱말(「미친 체」)만 `false` |
| `signs` | `drawable:false`면 ✓ | 본문이 그 곁에 적은 **보이는 표지** 항목 id 목록 |
| `meaning` | ✓ | `{ko, grounds}` — 아이도 알아듣는 뜻 |
| `look` | 그리는 항목 ✓ | `{L1, L2, L3, grounds}` — 각 단계 `{ko, en}` |
| `criteria` | 그리는 항목 ✓ | `{ko, features: [{q, grounds}]}` |
| `verified_level` |  | 그림 증거가 있을 때만(§3 규칙 7). 처음엔 없다 |

`drawable: false` 항목은 `look`·`criteria` 없이 `meaning`과 `signs`만 가진다.

## 3. 규칙

1. **근거 구절 원칙.** `refs`의 절마다 그 절 본문(`textKo`)에 `word`나 `forms` 하나가 들어 있어야 한다(용례 검증 — 띄어쓰기는 무시하고 비교). 범위 참조는 범위 안 어느 절이든 들어 있으면 된다. 같은 낱말의 다른 용례는 `data/word_verse_index`나 `data/bible/verses.json` 검색으로 찾는다. 외부 문헌·원어 사전은 이번 근거가 아니다(원어 자료는 저장소에 없음). **다른 구절에서 찾은 모양·크기 근거는 `grounds`에만** 둔다(그 절에 표제어가 없으면 `refs`에 넣지 않는다 — task 384: 골리앗의 칼 크기 근거 삼상 17:4-7, 진설병 덩이 수 근거 레 24:5-6). 인물의 지물은 그 장면 절만이 아니라 같은 인물·같은 물건이 나오는 다른 장까지 찾아 모양을 정한다(2026-10-21 사용자 방향 「다른 성경구절에서 찾아서 상세히 묘사」).
2. **근거 단계.** `meaning.grounds`·`look.grounds`·`criteria.features[].grounds`는 셋 중 하나로 **시작**한다.
   - `[직접]` 본문이 그 뜻·모양을 직접 말한다(구절 + 원문 인용).
   - `[추론]` 본문의 다른 사실(쓰임·재료·같은 낱말의 다른 용례)에서 끌어낸다(구절 + 추론 한 줄).
   - `[저작](이유)` 둘 다 없을 때 시대 고증이나 그림 사정으로 정한다 — 괄호 안 이유가 반드시 있다.
3. **아이 눈높이 대리 기준.** 기계로 재는 대리 기준이다.
   - `look` 단계별 `en` 낱말 수 상한: **L1 ≤ 8 · L2 ≤ 30 · L3 ≤ 60**.
   - `look.*.en`에 **추상어 금지 목록**이 없다: `pretend, feign, feigning, sacred, holy, ceremonial, symbolic, ritual, divine` (검사기 `FORBIDDEN`과 이중 관리 — 바꾸면 둘 다 고친다).
   - `meaning.ko`는 **2문장 이하·80자 이하**.
   - L2는 아이도 아는 낱말 한 문장, L3는 쥐는 법·크기(몸에 견줌)·쓰임까지.
4. **본문은 손으로 쓰지 않는다.** 구절 본문을 항목에 복사해 두지 않는다. 본문은 정본 절 사전에서 참조로만 푼다. `grounds` 안의 짧은 원문 인용(「…」)은 근거 표시라 허용한다.
5. **한 낱말 한 항목.** 같은 낱말은 장면이 달라도 같은 항목이다. `word`는 사전 안에서 하나뿐이다.
6. **설명 단계와 판정 기준의 쓰임.** `look`의 L1·L2·L3는 그림 문구용이고, 문구에는 한 단계만 들어간다. `criteria`는 그림을 **재는 데만** 쓰고 문구에 넣지 않는다. `features`는 예/아니오로 답하는 특징 문항 3개 이상, 문항마다 「?」로 끝난다.
7. **`verified_level`은 그림 증거로만 적는다.** `{level: L1|L2|L3, status: 확정|조건부, with: [함께 올린 항목 id]}`. 그 단계를 혼자 올려 맞았으면 `확정`(`with: []`), 다른 단위와 함께 올려 맞았으면 `조건부`(`with`에 함께 올린 id). 문구 한계·상한·밀어냄으로 멈춘 단위는 적지 않는다.
8. **낱말 묶음·보이는 표지.** 본문이 **함께 적어야 뜻이 서는** 낱말만 한 항목으로 묶는다(「보자기에 싸이다」「대문짝에 그적거리다」「침을 수염에 흘리다」). 낱낱이 나누면 그림 문구에서 서로 경쟁한다. 그릴 수 없는 낱말(「미친 체」)은 `drawable: false`로 두고, 본문이 그 곁에 적은 보이는 표지를 `signs`로 잇는다(삼상 21:13 → 대문짝에 그적거리다·침을 수염에 흘리다). `signs`의 id는 사전에 실재하는 **그리는 항목**이어야 한다.
9. **모양 설명에는 모양만.** `look`(L1·L2·L3)에는 그 물건·동작이 **어떻게 생겼는지**만 쓴다. 그 낱말이 나온 어느 한 순간의 사건(누가 건넴·누가 받음)은 넣지 않는다 — 단계 문구는 여러 장면에 그대로 들어가므로, 한 장면의 사건이 다른 장면의 순간과 부딪힌다(task 382: 진설병 L3 「a priest hands them over」가 21:6의 일인데 21:9 칼 건넴 장면에 들어감). 크기·무게처럼 그림에 보이는 성질은 근거와 함께 넣는다(골리앗의 칼 — 21:9 「그같은 것이 또 없나니」).

## 4. 역할

저작은 data-author, 검토는 scripture-reviewer(판정표 `.forge/reports/scripture-words-review.md`, 항목마다 맞음/약함/틀림)가 맡는다. 사람 검토 화면은 만들지 않는다.

## 크기 — `look.size` (2026-10-23, task 405)

그림에 들어가는 지물은 **사람 몸에 견준 크기**를 적는다. 사람 「창 앞촉이 큰것 같음 사람을 줄였으면 창도 줄여야하지 않아?」 — 그림은 지물을 장면 구역과 상관없이 제 크기로 그리므로(task 405 m4 실측), 크기를 사람에 묶어 두어야 사람 크기를 바꿀 때 지물도 같은 비로 따라간다.

```json
"size": { "ref": "man-height", "ratio": 0.67, "en": "two thirds of a man's height", "ko": "사람 키의 3분의 2쯤",
          "parts": { "point": { "en": "hand-sized", "ko": "손바닥만 함" } },
          "grounds": "[저작](본문에 길이 없음 — 그림 사정) …" }
```

편집 지시에 쓰는 부위 크기는 `parts.<부위>.edit_en`에 **편집 크롭 안에 보이는 것**(창이면 자루 굵기)에 견줘 적는다 — 크롭 밖의 손·머리에 견주면 편집 모델이 크롭 비율대로 부위를 키운다(task 405 m8e 사람 「창촉이 큰것 같음」, 규칙 edit.size-in-crop).

- `ref`는 지금 `man-height`(사람 키)만. `ratio`는 그 비 — 생성 규칙(`generate.flight-position`)이 그릴 길이를 셀 때 쓴다.
- `en`과 `parts.*.en`은 **L2 en에 그대로** 들어 있어야 한다(검사기·규칙 `derive.prop-size-relative`). L2 30낱말 한도 안에 짧은 꼴로.
- 본문에 크기가 없으면 `[저작]`으로 그림 사정임을 밝힌다(사람 판단이 바꿀 수 있는 칸).
