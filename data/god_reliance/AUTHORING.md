# 하나님 의존 분류 저작 규칙 (god_reliance)

각 인물이 "얼마나 하나님을 의지했나"를 [[하나님 의존도]] %로 보여주기 위해, 그 인물의
**하나님-상호작용 순간**을 5종 통제어휘 `mode`로 분류한다. 정본은 `data/god_reliance/<slug>.json`.
지표 정의·근거는 `.forge/adr/0023-god-reliance-metric-definition.md`.

각 순간은 **계기(trigger) → 결과(outcome) 2단 구조**로 저작한다 — 무엇이 그 순간을 촉발했고
(계기), 하나님/인물이 어떻게 반응했나(결과). 두 단 모두 구절 근거를 가진다. 명령 위반처럼
인물의 **행동**이 계기·결과와 구분되는 사건은 선택적 중간 단 `response`를 넣어 **3단
계기→행동→결과**로 저작한다(§1.1). **사건 단위 원칙**: 하나의 하나님-상호작용 사건은
**하나의 순간**으로만 센다 — 명령·행동·심판·후행 여파를 별도 순간으로 쪼개면 한 죄가 분모에
여러 번 계수되는 왜곡이 생긴다(예: 선악과 범죄를 명하심/따먹음/심판대/추방/930세 죽음 5개로
쪼개면 한 죄가 5번 계수 → 부르심 3단 한 순간으로 병합. ADR-0023 Amendment 2026-07-16).

## 1. 스키마

`data/god_reliance/<slug>.json` = 항목 배열. 각 항목:

```json
{ "mode": "물음-응답", "approxYear": -1003,
  "trigger": { "label": "블레셋 공격 여부를 여호와께 여쭘", "verse": "삼하 5:19" },
  "outcome": { "label": "'올라가라 내가 넘겨 주리라' 응답받음", "verse": "삼하 5:19", "kind": "이룸" } }
```

- `mode` (필수): 아래 §2 통제어휘 5종 중 하나.
- `approxYear` (필수): 정수 연도(BC는 음수). 궤적 정렬용.
- `obeyed` / `covenant` (부르심 전용·택일): `mode == "부르심"` 항목은 **정확히 하나**를 가진다 —
  **명령형**이면 `obeyed` 불리언(순종 `true`/불순종 `false`), **언약형**이면 `covenant: true`
  (§2의 명령형/언약형 구분). 그 외 mode엔 둘 다 넣지 않는다.
- `trigger` (필수): `{ label, verse }` — 그 순간을 촉발한 **계기**.
- `outcome` (필수): `{ label, verse, kind? }` — 계기에 대한 **결과**. `kind`는 **물음 계열**
  (`물음-응답`·`물음-침묵`)에만 붙는다(§3의 응답 성격).
- `trigger.label`·`outcome.label` (필수): 각 한 줄 담백 서술(≤ 약 45자).
- `trigger.verse`·`outcome.verse` (필수): 개역 약어 구절 참조("삼상 16:21", 범위는
  "16:21-23"도 허용). **각각 정본 사전 `data/bible/verses.json`에서 반드시 해석돼야 한다**
  (구절 근거 원칙 — 해석 안 되면 검증 실패).
- **같은 절 허용**: 계기와 결과가 한 절 안에 함께 있으면(요청과 응답이 같은 구절)
  `trigger.verse == outcome.verse`로 둘 다 그 절을 채운다. UI가 카드 1개로 합쳐 표시한다.
- **상위 호환 필드 금지**: 구 스키마의 최상위 `verse`·`label`은 넣지 않는다(검증 위반).

### 1.1 선택적 중간 단 `response` (3단 계기→행동→결과)

명령·부르심에 대한 **인물의 행동**이 계기(하나님의 명)와 결과(그 여파)와 뚜렷이 구분되는 사건은
`trigger`·`outcome` 사이에 선택적 `response`(`{ label, verse }`)를 넣어 3단으로 저작한다:

```json
{ "mode": "부르심", "approxYear": -4000, "obeyed": false,
  "trigger":  { "label": "선악과를 먹지 말라 명하심", "verse": "창 2:17" },
  "response": { "label": "명을 어기고 선악과를 따먹음", "verse": "창 3:6" },
  "outcome":  { "label": "죽음을 선고받고 에덴에서 쫓겨남", "verse": "창 3:19" } }
```

- `response`는 **선택적**이다 — 대다수 순간은 2단(계기→결과)이 맞고, 행동이 계기·결과와 별개
  구절로 서는 소수의 사건에만 쓴다.
- `response.label`·`response.verse`는 trigger·outcome과 **동일 규칙**(≤약 45자 담백 서술 + 정본
  사전 해석 필수). 검증기가 3단도 같은 규칙으로 검사한다.
- 명령이 먼저 있었으면 mode는 `독단`이 아니라 `부르심`이다(§2 독단↔부르심 경계). 결과 칩 어휘는
  서사에 맞춘다 — 선악과는 '재앙'이 아니라 **'심판'**(창3이 죽음·추방을 문자적으로 선고).

## 2. 통제어휘 (5 modes)

| mode | 판정 기준 |
|---|---|
| `물음-응답` | 인물이 **하나님께로 나아감** — 묻거나 기도·간구·의탁하거나 **믿음으로 예배·헌신** → 하나님이 응답·받으심·이루심 |
| `물음-침묵` | 인물이 하나님께 묻거나 기도했으나 → 침묵·거절·응답 없음 |
| `독단-개입` | 인물이 **하나님을 제쳐두고** 자기 판단으로 행함 → 그럼에도 하나님이 붙드심/개입/은혜 |
| `독단-어긋남` | 인물이 하나님을 제쳐두고 독단으로 행함 → 어그러짐/심판/실패 |
| `부르심` | 하나님이 **먼저** 이끄심(인물 주도 아님). **명령형**(행할 것을 명·부르심 → `obeyed`로 순종/불순종)과 **언약형**(창조·언약·택하심·예고 등 인물이 수령 → `covenant:true`, 결과 '받음')으로 나뉨 |

**mode별 계기 → 결과 의미:**

| mode | 계기(trigger) | 결과(outcome) |
|---|---|---|
| `물음-응답` | 인물의 요청·기도·예배·의탁 | 하나님의 응답·이루심·받으심 (+ `kind`) |
| `물음-침묵` | 인물의 요청·기도 | 침묵·거절·무응답 (+ `kind`, 보통 `침묵`/`거절`) |
| `부르심`(명령형) | 하나님의 명령·부르심 | 인물의 순종(`obeyed=true`)/불순종(`obeyed=false`) |
| `부르심`(언약형) | 하나님의 창조·언약·택하심·예고 | 인물이 **받음**(`covenant:true`, obeyed 없음) |
| `독단-개입` | 인물의 독단·자기 판단 행위 | 그럼에도 하나님의 붙드심·개입·은혜 |
| `독단-어긋남` | 인물의 독단·자기 판단 행위 | 어그러짐·심판·실패 |

**`독단` vs `물음` 경계(중요):** `독단`은 하나님을 **배제하거나 거스르는** 주제넘은 자기 판단이다(부정적 뉘앙스 — 사울의 자의적 제사, 다윗의 인구조사). **믿음의 예배·제사·헌신은 독단이 아니라 `물음-응답`이다** — 하나님께로 나아가는 의탁이기 때문(아벨의 믿음의 제물 히 11:4 → `물음-응답`, 다윗의 언약궤 예배 → `물음-응답`). 정의(ii)에서 `물음`은 의존의 표현(분자), `독단`은 그 반대편이므로 이 경계를 틀리면 믿음의 사람이 0% 의존도로 나오는 오류가 생긴다.

의존도 = (물음-응답 + 물음-침묵 + 순종한 부르심 + 언약형 부르심) ÷ 전체 × 100 (ADR-0023 정의 ii + 개정).
"물음"은 응답 여부와 무관하게 의존(분자), 부르심은 **순종(`obeyed=true`) 또는 언약형(`covenant:true`)**이 분자(둘 다 "하나님과 정렬"). 불순종한 명령형(`obeyed=false`)만 분모-only.
**mode·obeyed·covenant는 지표 구동값**이라 계수(분자/분모)를 바꾸지 않는다. `kind`는 표시 전용 — 지표에 무관.

**명령형 vs 언약형 판정:** 그 순간 인물이 **응답해 행한 행동**이 있으면 명령형(순종/불순종 — 가라·바치라·따르라·전하라). 하나님이 일방적으로 주시고 인물은 **수령자**면 언약형(창조·언약·택하심/기름부음·예고·신적 선언 "너는 내 아들" — `covenant:true`, 결과 label은 '받음/받아들임'류). 애매하면 **보수적으로 명령형(순종) 유지**.

## 3. 응답 성격 `kind` (물음 계열 전용)

물음 계열(`물음-응답`·`물음-침묵`) 항목의 `outcome`에, 요청 대비 하나님의 응답이 어떠했는지를
5종 통제어휘로 붙인다. **표시 전용**(의존도 % 무관). 다른 mode엔 `kind`를 넣지 않는다.

| kind | 판정 기준 | 전형적 mode |
|---|---|---|
| `이룸` | 구한 **그대로** 이루어짐 | 물음-응답 |
| `더하심` | 구한 것 **이상으로**(요청+α) 주심 | 물음-응답 |
| `다르게` | 구한 것과 **다른 방식**으로 응답하심(응답은 있으나 형태가 다름) | 물음-응답 |
| `거절` | 구하신 대로는 **주지 않으심**(명시적 안 됨) | 물음-침묵 |
| `침묵` | 응답이 **없거나 미루심**(무응답) | 물음-침묵 |

- `물음-응답`은 통상 `이룸`·`더하심`·`다르게` 중 하나(응답이 있었으므로).
- `물음-침묵`은 통상 `거절`·`침묵` 중 하나(응답이 없거나 거부됐으므로).
- 판정은 **성경 서사 근거**로만 한다(자유 인용·추측 금지). 애매하면 가장 담백한 값(`이룸` 또는 `침묵`).

## 4. 저작 규칙 (구절 근거 안전)

- **귀속 원칙.** 각 항목은 **그 인물이 직접 당사자인** 하나님-상호작용이어야 한다 — 하나님이
  그를 대면·그에게 행하셨거나, 그가 하나님을 향해 행한 순간. 하나님이 **제3자에게** 하신
  선언이나 인물 **미출생** 시의 예고는 그의 순간이 아니므로 넣지 않는다(예: 창 3:15 원시복음은
  뱀 대상 선언이라 아담에서 제외; 삿 13:5·눅 1:15 출생 예고는 부모가 받은 것이라 삼손·세례요한에서
  제외). 판정: "그 인물이 그 순간 현장에서 그 행위의 대상/주체인가?" — 본인 위에 선포·안수·지명된
  것은 당사자(유지), 남에게 말해진 것·태어나기 전 일은 아님(제외).
- **1:1 매핑(마이그레이션 한정).** 최초 flat→2단 **재저작**은 기존 flat 항목 하나를 **정확히
  2단 항목 하나로** 옮기며, 그 마이그레이션에서는 항목을 병합·분할하지 않고 `mode`·`approxYear`·
  `obeyed`를 시드 값 그대로 유지한다(재저작 전후 지표 % 불변 보장). **단 그 이후의 사건 단위 병합은
  허용된다** — 한 사건이 여러 순간으로 잘못 쪼개져 있으면 **사건 단위 원칙**(위 §서두)에 따라 하나의
  순간(필요시 3단 `response`)으로 병합한다. 이는 마이그레이션 불변식의 예외가 아니라, 마이그레이션
  *이후* 정확도 교정 작업이다(ADR-0023 Amendment 2026-07-16).
- **계기·결과절 출처.** `trigger.verse`·`outcome.verse`는 다음에서만 끌어온다:
  ① 그 항목의 기존 `verse`(기본 — 계기·결과가 같은 절이면 둘 다 그 절, `sameVerse`),
  ② 그 인물의 다른 god_reliance 항목 `verse`,
  ③ `data/person_relations/relations.json` 그 인물 `type:"하나님"` phase의 `verse`(이미 검증됨),
  ④ `data/person_events/<slug>.json` 사건 `books` rangeLabel을 개역 ref로 환산한 값.
  **두 절이 다를 때만 계기≠결과절**로 쓰고, 그렇지 않으면 같은 절(sameVerse)이 기본이다.
- **label 재작성.** 기존 `label`을 계기 문장 + 결과 문장으로 나눈다. 계기는 무엇이 그 순간을
  촉발했나, 결과는 하나님/인물이 어떻게 반응했나. mode별 의미(§2)에 맞춘다.
- **자유 인용 금지.** 위 정본에 없는 구절을 임의로 지어 인용하지 않는다(환각 방지) —
  근거는 이미 검증된 저작 데이터에서만 끌어온다.
- valence(관계 톤)와 mode(주도·응답 축)는 다른 축이다 — 긍정 valence여도 `독단-개입`일 수 있음.

## 5. 표본 적음

항목 수가 6개 미만인 인물은 %가 흔들리므로 [[하나님 의존도]] UI에서 "표본 적음" 뱃지로
신뢰도 한계를 밝힌다(제외하지 않음 — 32명 전원 저작). 성경 기록이 희소한 인물(아벨·에녹 등)이 해당.

## 6. 검증

`backend/scripts/validate_god_reliance.py` — mode 어휘·`trigger.verse`·`outcome.verse` 각각
정본 사전 대조·`obeyed` 배치 규칙·`kind`(물음 계열만 5값)·필드 결손·구 스키마(최상위
`verse`/`label`) 잔존을 검사. 위반 0이어야 한다.
