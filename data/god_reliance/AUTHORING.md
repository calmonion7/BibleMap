# 하나님 의존 분류 저작 규칙 (god_reliance)

각 인물이 "얼마나 하나님을 의지했나"를 [[하나님 의존도]] %로 보여주기 위해, 그 인물의
**하나님-상호작용 순간**을 5종 통제어휘 `mode`로 분류한다. 정본은 `data/god_reliance/<slug>.json`.
지표 정의·근거는 `.forge/adr/0023-god-reliance-metric-definition.md`.

## 1. 스키마

`data/god_reliance/<slug>.json` = 항목 배열. 각 항목:

```json
{ "mode": "물음-응답", "verse": "삼하 5:19", "approxYear": -1003,
  "label": "블레셋 공격 여부를 여쭤 '올라가라' 응답받음" }
```

- `mode` (필수): 아래 §2 통제어휘 5종 중 하나.
- `verse` (필수): 개역 약어 구절 참조("삼상 16:21", 범위는 "16:21-23"도 허용). **정본 사전
  `data/bible/verses.json`에서 반드시 해석돼야 한다**(구절 근거 원칙 — 해석 안 되면 검증 실패).
- `approxYear` (필수): 정수 연도(BC는 음수). 궤적 정렬용.
- `label` (필수): 한 줄 담백 서술(≤ 약 45자). 무슨 순간인지 + 응답/결과.
- `obeyed` (조건부): **`mode == "부르심"`일 때만** 존재하는 불리언. 인물이 그 부르심에
  순종했으면 `true`, 불순종했으면 `false`. 그 외 mode엔 넣지 않는다.

## 2. 통제어휘 (5 modes)

| mode | 판정 기준 |
|---|---|
| `물음-응답` | 인물이 **하나님께로 나아감** — 묻거나 기도·간구·의탁하거나 **믿음으로 예배·헌신** → 하나님이 응답·받으심·이루심 |
| `물음-침묵` | 인물이 하나님께 묻거나 기도했으나 → 침묵·거절·응답 없음 |
| `독단-개입` | 인물이 **하나님을 제쳐두고** 자기 판단으로 행함 → 그럼에도 하나님이 붙드심/개입/은혜 |
| `독단-어긋남` | 인물이 하나님을 제쳐두고 독단으로 행함 → 어그러짐/심판/실패 |
| `부르심` | 하나님이 **먼저** 부르심·명하심·언약하심(인물 주도 아님). `obeyed`로 순종/불순종 구분 |

**`독단` vs `물음` 경계(중요):** `독단`은 하나님을 **배제하거나 거스르는** 주제넘은 자기 판단이다(부정적 뉘앙스 — 사울의 자의적 제사, 다윗의 인구조사). **믿음의 예배·제사·헌신은 독단이 아니라 `물음-응답`이다** — 하나님께로 나아가는 의탁이기 때문(아벨의 믿음의 제물 히 11:4 → `물음-응답`, 다윗의 언약궤 예배 → `물음-응답`). 정의(ii)에서 `물음`은 의존의 표현(분자), `독단`은 그 반대편이므로 이 경계를 틀리면 믿음의 사람이 0% 의존도로 나오는 오류가 생긴다.

의존도 = (물음-응답 + 물음-침묵 + 순종한 부르심) ÷ 전체 × 100 (ADR-0023 정의 ii).
"물음"은 응답 여부와 무관하게 의존(분자), 부르심은 `obeyed=true`만 분자.

## 3. 저작 규칙 (구절 근거 안전)

- **1차 = 시드 재분류.** 그 인물의 `data/person_relations/relations.json` `type:"하나님"`
  phase(이미 구절 근거 검증됨)를 그대로 가져와 각 phase를 mode로 재분류한다. `verse`·
  `approxYear`는 시드 값을 재사용. `label`은 시드 `label`을 다듬어 응답/결과가 드러나게.
- **2차 = person_events 보충.** `data/person_events/<slug>.json`에서 명백한 하나님-상호작용
  사건(기도·여쭘·명령·언약 등)을 골라 그 `books` rangeLabel을 개역 ref로 환산해 항목 추가.
- **자유 인용 금지.** 위 두 정본에 없는 구절을 임의로 지어 인용하지 않는다(환각 방지) —
  근거는 이미 검증된 저작 데이터에서만 끌어온다.
- valence(관계 톤)와 mode(주도·응답 축)는 다른 축이다 — 긍정 valence여도 `독단-개입`일 수 있음.

## 4. 표본 적음

항목 수가 6개 미만인 인물은 %가 흔들리므로 [[하나님 의존도]] UI에서 "표본 적음" 뱃지로
신뢰도 한계를 밝힌다(제외하지 않음 — 32명 전원 저작). 성경 기록이 희소한 인물(아벨·에녹 등)이 해당.

## 5. 검증

`backend/scripts/validate_god_reliance.py` — mode 어휘·verse 해석(정본 사전 대조)·`obeyed`
배치 규칙·필드 결손을 검사. 위반 0이어야 한다.
