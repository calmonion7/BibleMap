# 정답지 — [[화풍 도달]] 판정의 양성 기준 (task#317 S0-1)

**이 10장은 지어낸 것이 아니라 사용자가 2026-08-24에 목표로 제시한 그림이다**(CONTEXT.md
[[화풍 도달]]). ADR `260824-002411`이 매체 교체(선화 → 래스터)의 근거로 삼은 바로 그 산출물이고,
`.forge/reports/raster-pilot/`에서 생성됐다(생성 기록은 그 디렉터리의 `FINDINGS.md`).

**여기로 옮긴 이유는 휘발 때문이다.** 원래 자리 `.forge/reports/`는 `.gitignore` 28행이 덮는
미추적 경로다 — 판정의 **기준 자체가 사라질 수 있는 상태**였다. 회고 `260824-191250` 교훈 5가
같은 자리에서 이미 한 번 값을 잃었다(산출 경로가 추적되지 않아 통계를 다시 셌다). 그리고
`scripts/` 아래는 `backend/scripts/validate_canon_pipeline.py` 축2가 **미추적 파일 하나에도
배포를 막으므로**, 이 자리에 두는 것이 곧 추적의 기계적 강제다.

## 이 정답지를 무엇에 쓰고, 무엇에 쓰지 않나

- **쓴다**: `judge_style.py`가 축 A 임계를 **여기서 파생한다**. 리터럴로 적지 않는다
  (ADR `260823-221839`).
- **쓰지 않는다 — 축 C(구도)의 양성 기준이 아니다.** 이 10장은 전부 ControlNet 없이 뽑았고
  콘티를 따르지 않는다. 축 C에서는 **음성 대조군**이다(통과하면 축 C 지표가 틀린 것이다).
  한 이미지 집합이 한 축의 양성이면서 다른 축의 음성인 것이 이 파일럿이 푸는 긴장 자체다.
- **쓰지 않는다 — 초상 판정.** 축 A 지표의 적용 범위는 장면류다. 동결 정본(얼굴 클로즈업)은
  같은 지표에서 실패해야 할 현행 장면과 같은 값(0.006)을 낸다
  (ADR `260825-013557` 2026-08-25 개정 따름 정리 3).

## `arm-negatives/` — 정답지가 **아닌** 고정 자산 (2026-08-30, task#322 R4)

`approved-320-s{11,7}.png`(task#320 승인본)는 축 G의 음성 대조군으로 **화소 신원을 고정하려고**
git 추적 위치가 필요했다(생성기 산출물 이름이 콘티 판본을 안 담아 덮어쓰기가 일어난다 —
`judge_s1.py`의 `ARM_APPROVED` 주석). 그런데 `reference/` **바로 아래**에 두었더니
`judge_style.reference_paths()`가 `reference/*.png` 전부를 정답지로 읽어 두 장을 위 표의 10장과
같은 부류로 삼켰다. 두 장은 **콘티 ControlNet으로 뽑은 장면**이라 위 불변식(「전부 ControlNet
없음」)을 깬다 — 축 C 음성으로 통과해(0/16 → 2/18) 축 C가 게이트에서 빠졌다.

그래서 하위 디렉터리로 내렸다. glob이 비재귀라 정답지 집합은 위 표의 10장 그대로다.
**여기에는 정답지를 넣지 않는다** — 이 폴더는 「추적은 필요하지만 정답지가 아닌 대조군」 자리다.
