# 옆얼굴 표본 실험 — 기전은 증명됐고 프레이밍 조율이 남았다 (2026-08-31)

사용자가 갈림길 ⓑ(옆얼굴 표본)를 승인해 연 실험. `goliath-profile-portrait-src.png`가
그 원천이다 — `gen_sample.py goliath --no-ref --portrait --profile`로 뽑은 **옆얼굴 초상**
(엄격한 옆얼굴 · 사람 · 뿔투구 · 수염 없음 · 머리카락 안 보임). 좌우반전해 왼쪽을 보게 쓴다.

## 세 판본 실측

| 판본 | 레퍼런스 | 회전 | 사람 | 프레이밍 | 전 축 |
|---|---|---|---|---|---|
| A | 옆얼굴 초상 그대로(클로즈업) | ✅ 3/3 | ✅ | ❌ 넘침·잘림 | 0/3 |
| B | 옆얼굴 머리 + **표본의 실제 어깨** 합성 | △ 1/3 | ✅ | ✅ | **1/3** |
| C | 옆얼굴 머리만(어깨 없음) | △ | ✅ | △ 불안정 | 0/3 |

**A가 증명한 것**: 옆얼굴 레퍼런스는 골리앗을 **돌리면서 사람으로 유지한다** — §9-36이 적은
「회전과 사람다움이 반비례한다」가 **깨졌다.** 남은 것은 원인이 아니라 **프레이밍 결합**이다
(`gen_sample` 시도 1의 「레퍼런스 프레이밍이 산출물로 전이된다」와 같은 자리).

`samples/goliath-profile.png`에는 **판본 B**를 둔다(셋 중 최선, 완벽한 시드 1장 —
`--head-ref goliath=profile`이 이 파일을 쓴다).
