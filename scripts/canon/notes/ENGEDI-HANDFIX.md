# 엔게디 손 국소 수정 — 마주 봄 없는 B 그림에서 다윗 손·칼만 다시 그림 (2026-10-18, task 367 뒤 사용자 선택)

사용자: 「똑같은 판정을 계속하는것 같은데 피드백을 했으면 고쳐져야 하는거 아닌가?」 → 고를 길로 「마주 봄이 없는 B 그림에서 다윗 손 부분만 국소 수정하는 방법」.
- 대상: 365 B 그림 중 367 판정에서 **손·칼만** 눌린 4장(s7·s11·s101·s202 — 마주 봄 0, 시선·가드 안 눌림).
- 수단: `gen_engedi_handfix.py` — Z-Image-Turbo Q8 인페인트(`gen_face_ab.py` 틀: 손 상자 2.6배 정사각 크롭 → 768 → 타원 마스크 → 9스텝 → 마스크 안쪽만 되붙임). 손 상자는 눈으로 잡음. 장당 약 40초.

## r1 (크롭 = gen_face_ab.crop_mask, 문구에 STYLE 그대로, 강도 0.85·1.0 × 시드 1·2)
- 손이 갈리고 칼날이 보이는 그림이 생겼지만, 손 부위에 흰 크림색 얼룩·사진 같은 손·부엌칼만 한 칼·손 하나 더가 섞였다(특히 s7).
- 원인: 손이 그림 아래쪽이라 크롭이 아래로 넘쳐 크림색 종이로 채워졌다(그 색이 마스크 안까지 번짐). 강도 1.0은 망가진 것이 더 많다.

## r2 (크롭을 그림 안으로 당김 + 「dim cave · dark sepia · hatching」 문구 + 「blade no longer than a finger」, 강도 0.75·0.85 × 시드 1·2)
- 흰 얼룩이 없어지고 화풍이 주변과 이어진다. 16장 중 다수가 「한 손 자락 들기 + 한 손 칼」로 갈린다. 칼은 아직 조금 큰 것이 있다(s101 0.85 i1).
- 눈으로 고른 시드별 하나: s7 0.75 i2 · s11 0.75 i2 · s101 0.75 i2 · s202 0.85 i2. 전체 그림에서 이음매가 보이지 않고, 마스크 밖(사울 등 돌림·다윗 시선)은 원본 그대로다.
- 산출(레포 밖): `~/.local/biblemap-imggen/engedi-handfix/<r1|r2>/B<시드>-st<강도>-i<시드>.png`.
