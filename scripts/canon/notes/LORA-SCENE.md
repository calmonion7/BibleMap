# 인물 LoRA 장면 판정 — 사울·다윗·사무엘 (task 357, 인물 LoRA 2/2)

353 결론: 정의 문구만으로 그린 장면은 카드 크기 같은 인물 1/9. 이번에는 356 시트로 학습한 인물 LoRA를 장면 전체 생성에 걸어 같은 판정을 한다. 결과로 ADR `260904-055320`(어휘 정본 1층, 얼굴 앵커는 자격 게이트)을 새 ADR로 뒤집을지 정한다.

## 고정 절 (학습·생성 전 작성 — 결과를 보고 바꾸지 않는다)

### 시트 (356 `notes/LORA-SHEET.md` 「최종 시트」에서 옮김)

| 인물 | 캡션 쌍 | 구성 |
|---|---|---|
| 사울 | 13 | 정본 초상 6 + 전신 7(정본 머리 되붙임 6 + 문구 walk-s23 1) |
| 다윗 | 14 | 정본 초상 6 + 전신 8(되붙임 7 + 문구 walk-s23 1) |
| 사무엘 | 14 | 정본 초상 6 + 문구 전신 8 |

캡션 = `<트리거>, a man, <구도·자세·배경>`. 트리거 `saul_bm`·`david_bm`·`samuel_bm`. 전신은 대부분 정면 서기다(자세 다양성 낮음 — 결과 해석 때 참고).

### 학습

- `mflux-train`(`~/.local/biblemap-imggen/.venv-mflux`), 설정 = 346 `train/saul.json`과 **같고 `data`·`output_path`만** `lora-sheet-v2/<id>`·`train/<id>-v2`로 바꿈(`train/<id>-v2.json`). z-image-turbo, quantize 8, rank 16(to_q·k·v·out, ff w1~w3, 블록 0~30), AdamW 1e-4, 25에폭, 체크포인트 60스텝마다.
- 시트가 13~14장이라 25에폭이면 325·350스텝을 돈다. **346의 300스텝에 맞춰 `0000300` 체크포인트의 어댑터를 쓴다** → `~/.local/biblemap-imggen/lora/<id>-v2.safetensors`.
- 3명을 **차례로** 한 백그라운드 프로세스로(피크 30.7GB라 동시 금지, 다른 생성과도 겹치지 않음).

### 생성

- 경로 = `batch/run_scene.gen_zimage`와 같은 diffusers GGUF Q8 경로에 `load_lora_weights` + 어댑터 이름, 세기 **1.0 한 값**. 두 어댑터를 동시에 걸 수 없으면 L2는 「불가」로 적고 L1만 판정한다(우회 구현 없음).
- 문구 = `derive_scene.whole_prompt(spec)`(353과 같음)에서 LoRA를 건 인물의 `cast_describe` 앞에 트리거 낱말만 붙인다.
- 시드 `[11, 42, 7, 23, 5, 101, 202, 303]`, 1216×640(345 한 장 모드).
- **L1** = 장면 3 × 그 장면 정본 인물 2(그 인물 LoRA 하나만) × 시드 8 = 48장. **L2** = 장면 3 × 두 인물 LoRA 동시 × 시드 8 = 24장. 합 72장.
- 일괄 전에 L1 1장·L2 1장을 먼저 본다(LoRA가 먹는지 · 화풍/구도 붕괴 · 두 어댑터 동시 가능 여부).
- 산출은 레포 밖 `~/.local/biblemap-imggen/lora-scene/`, 목록·시간·머리 상자는 `samples/lora-scene/metrics.json`.

### 판정 규칙

- **보기 방식은 353·351 고정 절과 같다.** 카드 폭 356 CSS px(DPR 3), 확대·크롭 없음, 대상 머리 위 ▼(OWLv2 `face_ab_heads`, 못 찾으면 명세 구역 위), 두 장면은 위/아래로 쌓는다.
- **화면 A — 같은 인물(6화면 = 인물 3 × L1/L2).** 쌍 = 그 인물이 나오는 두 정차지(사울 길갈↔엔게디, 다윗 엔게디↔라마, 사무엘 길갈↔라마)의 같은 시드끼리 8쌍 + 음성 대조 3쌍(353 `cast-v2-pilot/scene/<장면>/s{11,42,7}.png` 같은 시드끼리 — LoRA 없음)을 섞어 11쌍. 순서는 고정 시드 357로 섞고, 대조인지는 표시하지 않는다. 문항: 「두 ▼가 같은 사람으로 읽히는 쌍을 누르기」.
- **화면 B — 섞임(3화면 = 장면마다).** L2 8장에 「두 ▼ 인물이 서로 닮아 구별이 안 되는 그림을 누르기」.
- **화면 C — 화풍·뜻(3화면 = 장면마다).** 기준 그림(345 승인본, 라마는 353 s11) 아래에 L1·L2 그림을 두고 「연필 화풍이나 장면 뜻이 기준보다 크게 무너진 그림을 누르기」.
- **분해능 조건:** 음성 대조 「읽힌다」 합이 9쌍 중 **3쌍 이하**(353 실측 1/9). 넘으면 판정이 차이를 가르지 못한 것으로 보고 `판정: 보류`. L1·L2 화면에 같은 대조 쌍이 두 번 나오므로 답 일치도 적는다(참고).
- **결론:**
  - **채택** = 분해능 조건 충족 + L1에서 인물마다 「읽힌다」 **≥ 5/8**, 3명 모두. L2·섞임·화풍은 함께 적되 채택을 막지 않는다. 다만 화풍 「무너짐」이 L1의 절반을 넘으면 조건부로 내린다.
  - **조건부** = L1을 2명만 충족, 또는 L1은 충족했지만 화풍 무너짐이 절반을 넘음.
  - **다른 길** = 그 밖. 끝에 다음 후보(외부 조사 — 참조 어댑터·다중 참조 편집)를 한 줄 적는다.
  - 채택이면 ADR `260904-055320`을 뒤집는 새 ADR(실측표 포함). 조건부·다른 길이면 그 ADR 개정 메모에 결과 한 줄만.
