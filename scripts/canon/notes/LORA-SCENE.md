## 판정

판정: 다른 길

- 규칙: 채택 = 분해능 충족 + L1 인물마다 ≥ 5/8, 3명 모두. 조건부 = L1 2명만 충족. → **L1 충족은 사무엘 1명(8/8)**, 사울·다윗 2/8 → 다른 길.
- 읽을 것: **사무엘은 LoRA로 장면 사이 같은 인물이 됐다**(353 0/3 → L1 8/8·L2 7/8, 대조 0/3이라 판정이 가른 차이). 사울·다윗은 353 수준에서 크게 나아지지 않았다(다윗 L1 2/8 ≈ 대조 1/3).
- 사무엘과 사울·다윗의 차이로 보이는 것(짐작, 확인 안 함): ① 시트 — 사무엘은 문구 전신 8장이 그대로 남았고, 사울·다윗 전신은 정본 머리를 붙인 그림(가분수 거른 뒤 6~7장)이었다. ② 얼굴 — 사무엘은 흰 긴 머리·가슴까지 흰 수염이 카드 크기에서도 큰 단서인데, 사울·다윗은 둘 다 「짧은 검은 수염의 남자」라 작은 얼굴 차이에 기댄다.
- 엔게디는 L1·L2 전부 「화풍·뜻 무너짐」이었다(대조 없음 — 위 주의).
- **다음 후보(외부 조사):** 참조 어댑터(PuLID·InfiniteYou 계열)·다중 참조 편집(Qwen-Image-Edit 계열) — 특히 젊은 수염 남자 둘(사울·다윗)처럼 카드 크기 단서가 작은 인물. 그전에 싸게 확인할 것: 엔게디 353 장면도 345 기준으로 「무너짐」인지(화면 C 대조).
