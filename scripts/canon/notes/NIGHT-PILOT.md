# NIGHT-PILOT — 밤샘 5장면 × 8시드 + 아침 요소 문항·고르기 (task 368)

장면당 사람 판정을 아침 한 번으로 줄인다. 기계가 밤새 후보(바탕 + 정본 참조 편집)를 모두 만들고, 사람은 아침에 장면 요소마다 쪼갠 문항에 답한 뒤 장면마다 하나를 고른다.

## 고정 절 (실행 전, 2026-10-19 00:10 KST)

- 장면·순서·편집 인물: `params.NIGHT_SCENES` — 기브아 창(사울 → 다윗) · 미스바 제비뽑기(사울) · 믹마스(사울) · 길갈 아말렉(사울) · 사무엘 죽음·라마(다윗). 편집 6건.
- 시드: `params.NIGHT_SEEDS` = `REF_EDIT_SEEDS` [11, 42, 7, 23, 5, 101, 202, 303].
- 바탕: Z-Image 한 장, 1216×640, `derive_scene.plate_whole_prompt` — **다섯 장면에 한 장 모드 칸(whole_background·표정·몸짓·차림·시선·관계)이 없어** 명세의 판 단계 문구(배경 + 구역·무리 + 인물별 「위치: 정본 서술, 자세·지물·방향」 + `groups` 묶음 문구)를 기계적으로 잇는다(2026-10-18 루프 시작 때 사용자 결정, 명세 수정 없음). 512토큰 안이어야 한다.
- 편집: `gen_ref_edit_lightning`과 같은 2511 + Lightning 4스텝 q8. `{look}` = `REF_EDIT_LIGHTNING_LOOK_IDENTITY` + 차림(장면 명세 `costume`이 없으므로 바탕 문구가 쓴 인물 카드 차림). 정본 튜닉 서술(`LOOK_IMAGE`)은 쓰지 않는다.
- 기계 거르기 없음. 사람만 고른다(ADR 260905-104910).

### 판정 규칙
- 장면마다 요소 문항에서 항목마다 「틀린 시드 목록」을 받는다. 문항 id = 명세 칸 경로: `moment` · `background[i]` · `crowds` · `figures[i].identity` · `figures[i].pose` · `figures[i].prop` · `figures[i].facing` · `guard`.
- 장면마다 마지막 답 하나: `s<시드> 편집본` · `s<시드> 바탕` · `없음`.
- 사람 소요 시간 = 페이지 첫 화면을 연 때부터 「판정 문장 복사」까지(장면별도). 참고값 — 결론 규칙 밖.
- 산출 표: 요소 × 장면 「틀린 시드 수 / 8」, 고른 장의 틀린 항목(= 그 장의 고칠 곳).
- 결론: **채택** = 5장면 중 4장면 이상 고름 → 확대 + 고칠 곳 국소 수정, ADR 260905-104910 개정 · **부분** = 2~3장면 → 틀린 시드가 가장 많은 명세 칸 처치(같은 문구 A/B 금지) · **다른 길** = 1장면 이하.
- 바탕으로 고른 장면 수는 따로 센다(결론 규칙 밖).
