# FACE-LORA-V3 — 각도 정본으로 다각도·원경 시트를 만들어 인물 LoRA를 다시 학습하면 장면 속 사울·다윗이 정본과 같은 사람이 되는가 (2026-10-22)

FACE-ANGLES 결론: klein 4B 각도 정본(3/4·옆얼굴)은 사람 승인 4/4, 그러나 klein으로 장면 얼굴만 다시 그리기는 0/32 → 그 수단 중단. 357 LoRA v2는 사무엘 8/8·사울·다윗 2/8이었고, 원인 짐작은 「정면 초상 + 정면 전신(가분수)뿐인 시트 — 장면의 작은 옆얼굴이 학습 범위 밖」. 이번에는 **시트만** 바꿔 다시 학습한다(사용자 「진행」).

## 고정 절 (실행 전 — 그림·판정을 보기 전에 적음)

- **시트 v3**(인물마다, `~/.local/biblemap-imggen/lora-sheet-v3/<id>/`): 캡션 = `<트리거>, a man, <구도>`(v2와 같은 꼴 — 수염·나이·체격 같은 정체성 낱말은 넣지 않음).
  - 초상 13 = 정면 정본 1 + 각도 정본(3/4 시드 11·42·7, 옆얼굴 시드 11·42·7 — FACE-ANGLES `views/`) 6 + 그 좌우 반전 6.
  - 전신 8 = klein 4B, 참조 [정면 정본, 3/4 고른 장], 자세 4(허리 위 3/4 · 꿇어앉은 옆모습 · 걷는 3/4 · 선 옆모습, `params.LORA_V3_BODY`) × 시드 11·42, 768×1152.
  - 원경 4 = 걷기·서기 전신을 화면 높이 0.45·0.38로 줄여 1216×640 빈 바탕에 놓음(장면 속 작은 인물 — 이 그림의 정체성은 줄이기 전 전신에서 온다).
    - 덧붙임(학습 전, 원경 합성을 보고): 걷기 전신은 풍경 배경이 있어 줄이면 빈 바탕 위에 풍경 사각형이 액자처럼 붙는다 → 원경 재료를 빈 바탕인 **서기 0.38·꿇어앉기 0.30**으로 바꿈.
  - 전신 16장 거르기: 뺀 장 없음(가분수·다른 사람·두 사람 없음). 기록: 걷기 그림의 하의가 무릎 바지(시대감 약간 어긋남) — 캡션에 옷이 없어 LoRA가 옷을 배울 수 있으나 장면 문구가 옷을 지정하므로 그대로 둠.
  - 전신·원경은 Claude가 눈으로 먼저 거른다(가분수·다른 사람·두 사람 등). 거른 장은 빼고 기록한다(다시 그리지 않음).
- **학습**: v2 설정 그대로(`train/<id>-v2.json` 복사 — z-image-turbo, quantize 8, rank 16, AdamW 1e-4), 바꾸는 것은 `data`·`output_path`, 그리고 에폭 수를 **300스텝이 되게**(v2도 300스텝 어댑터를 씀). 사울 → 다윗 차례로(피크 약 31GB, 동시 금지). → `lora/<id>-v3.safetensors`.
- **장면 비교**: 기브아 창(`authored-saul-gibeah-spear`), 시드 `[11, 42, 7, 23, 5, 101, 202, 303]`, 1216×640, 문구 = `gen_lora_scene.prompt`(353 `whole_prompt`에 LoRA 인물 서술 앞 트리거 낱말만).
    - 덧붙임(생성 전, 첫 실행 실패 뒤): 기브아는 한 장 모드 칸이 없는 판 경로 장면이라 `whole_prompt`가 KeyError → 문구를 `route_prompt`(= `plate_whole_prompt`)로 바꿈. C 문구는 368 바탕 문구와 글자까지 같음을 확인(같은 시드 → C는 368 바탕 재현), V2·V3는 트리거 낱말 둘만 더함.
  - **C** = LoRA 없음(트리거 없음) · **V2** = 사울·다윗 v2 동시 · **V3** = 사울·다윗 v3 동시. 세기 1.0(`LORA_SCENE_SCALE`).
- **사람 판정**(폰 비공개 Artifact, 한 화면 한 질문 — FACE-ANGLES 화면과 같은 꼴):
  - 머리 크롭 48장(3갈래 × 8시드 × 2인물)을 섞어 갈래 이름 없이 「정본(정면·3/4)과 같은 사람인가」 예/아니오/모르겠음. 머리 상자는 OWLv2(`face_ab_heads`) — 그림마다 새로 찾는다(바탕이 서로 달라서).
  - 화풍·장면 24문항: 그림 한 장씩 「화풍이나 장면(창 든 사울·수금 타는 다윗)이 무너졌나」 예/아니오.
- **채택 규칙**(인물마다):
  - **채택** = V3 「같은 사람」 ≥ 5/8 **그리고** V3 − C ≥ 3, 두 인물 모두. 단 V3 화풍·장면 「무너짐」이 8장 중 4장을 넘으면 조건부로 내림.
  - **조건부** = 한 인물만 채택 조건 충족, 또는 무너짐이 절반 넘음.
  - **미채택** = 그 밖.
  - V3 − V2는 시트 효과로 적는다(결론엔 안 씀). C가 3/8 이상이면 판정이 너그러운 것으로 보고 결론 옆에 적는다.
- 크롭 되붙이기 없음. 그림은 레포 밖, 목록·판정은 `samples/face-lora-v3/`.

판정: **미채택** (V3 사울 1/8·다윗 1/8 < 5/8)

- 화풍·장면 24문항은 **무효**: 한 질문에 화풍과 장면 뜻을 섞었고, 판정 화면에 성경 원문을 넣지 않았다(메모리 「판정 화면에 성경 원문」 위반 — Claude 실수). 사람 메모 「장면 구절이 없어서 판단이 어렵고 — 사울이 창을 던지려는 장면? 다윗이 수금으로 귀신들림을 낮춰 주는 장면?」 → 24장 모두 「무너짐」은 장면 뜻(순간이 읽히지 않음)에 대한 답으로 읽는다.
- **원인은 명세**: `moment.why` = 「창을 던지는 동작과 다윗이 피하는 장면(18:11)은 모델 prior에 없는 동작이라 그리지 않는다」 — 10-20 규칙 「구절 묘사 타협 금지」(`VERSE_ELEMENT_BANNED`) 위반. 18:10 「악신이 힘있게 내리매 … 야료하는」 사울 상태도 빠짐(몸짓·표정 칸 없음). 이 규칙은 375의 14장면에만 걸려 있어 이 명세는 검사 밖이었다.
- **같은 규칙을 37명세 전부에 돌림**: 3/37 위반 — 기브아 창, 솔로몬 배교(jerusalem-apostasy), 솔로몬 성전 건축(jerusalem-temple-build). 셋 다 375 목록 밖.
- 얼굴: 세 수단(klein 다시 그리기 0/32, LoRA v2 0/16, LoRA v3 2/16)이 모두 사람 기준에 못 미침. 참고 — 368에서 같은 장면 사울 identity는 「다른 사람」 1/8이었는데(편집본·정본 정면만 표시), 이번엔 C 0/8 「같은 사람」(정면·3/4 정본을 나란히 표시). 판정 화면 꼴에 따라 얼굴 판정 기준이 크게 달라진다 — 얼굴 문항의 표시 방식부터 규칙으로 고정해야 한다.
- 사람 메모(추가) 「화질이 달라서 판단이 어려움」: 정본은 768px 선명한 초상, 장면 머리는 30~60px 크롭을 320px로 키운 흐린 그림 — 같은 사람도 「다르다」로 기울기 쉽다. 이 화면의 얼굴 답(C·V2·V3 모두)은 이 편향을 안고 있다. **얼굴 문항 표시 규칙(다음 시험 전 고정)**: ① 정본을 보일 때는 그 장면 머리와 같은 화소로 줄였다가 같은 방식으로 키워 화질을 맞춘다, 또는 ② 정본 대신 같은 인물이 나오는 두 장면의 머리를 같은 크기로 나란히(장면 대 장면 — 앱에서 필요한 것이 「장면마다 같은 사람」), ③ 성경 원문을 함께.

다음 과제: (1) 규칙 원장 + 전 명세·전 그림 재검 명령 — 금지 낱말 규칙처럼 일부에만 걸린 규칙을 전부에 걸기(첫 결과 3/37). (2) 위반 명세 3개를 장면 구절 전부로 재저작(기브아는 18:10~11 — 야료하는 사울·창 던짐·다윗 피함). (3) 얼굴 판정 화면의 표시 규칙(정본 몇 장·크롭 크기·원문) 고정 뒤 다시.
