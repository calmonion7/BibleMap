# LoRA 학습 묶음을 장면 화풍으로 — v5 (task 448)

447에서 LoRA 화풍 붕괴의 원인이 **학습 묶음의 사실풍 초상 화법**으로 좁혀졌다(`LORA-STYLE.md` 「사람 판정 — 미채택」). 이번엔 묶음 쪽을 고친다: 다윗 청년 묶음(`face-lora-v4/raw/david-youth`, 25장)을 더 센 다시 칠하기로 장면 화풍에 맞추고, 학습(약 2시간 20분) 전에 **머리 둘레 화풍 자동 측정**(DINOv2 Gram, `STYLE-METRIC.md`)으로 관문한다.

- 스크립트 `gen_lora_v5.py` · 상수 `params.LORA_V5_*` · 수치 `samples/lora-v5/metrics.json` · 그림 레포 밖 `~/.local/biblemap-imggen/lora-v5/`.
- 하지 않음: 승인 장면에서 인물 잘라 학습(정본 얼굴이 아님) · 사울 묶음 · 얼굴(정체성) 사람 판정 · 참조 어댑터.

## 고정 절 — 생성 전에 적음(결과 보고 고치지 않음)

**머리 둘레 자르기(모든 그림 같은 길)**: OWLv2(`face_ab_heads._faces`) 점수 0.05 이상 후보 중 **가장 큰 상자**(447 `heads`와 같은 이유 — 머리털까지 든 머리 전체) → `gen_face_detail.region`(긴 변 × 2.4 정사각) → 3배 LANCZOS. 장면은 왼쪽 절반(다윗 — 수금) 후보만. 묶음 그림은 먼저 머리 상자 긴 변이 **기브아 C 다윗 머리 상자 긴 변 중앙값**과 같아지게 줄이거나 키운 뒤 같은 길로 자름(장면 머리와 화소 밀도를 맞춤). 상자를 못 잡은 장은 빼고 셈(몇 장 뺐는지 기록).

**화풍 자**: `style_metric.feats`(DINOv2-base 짧은 변 476, Gram 2·6층, 정규화) — 두 그림 거리 = 1 − 코사인.

**S1 측정자 맞춰 보기(GPU 0)**: 기준 = C 다윗 머리(445 C 8 + 447 C 1 = 9). 맞음 = C 머리 9(점수 = 자기 빼고 나머지 C 8과의 평균 거리) · 틀림 = 445 L 8 + 447 L·K5·K3·R 4 = 12(점수 = C 9와의 평균 거리; 사람 「다름」은 시드 11만 직접 물음 — 나머지 L 시드는 [추론] 같은 갈래). 층마다 AUC. **Gram 2층 또는 6층 AUC ≥ 0.9 → `관문으로 씀`**, 관문 층 = AUC ≥ 0.9인 층, 층마다 **문턱 = 맞음 점수 최댓값**. 그림 하나가 「문턱 안」 = 관문 층 모두에서 C 9와의 평균 거리 ≤ 문턱. 둘 다 0.9 미만이면 `관문 아님` → 묶음 관문은 Claude 눈(원래 화소 같은 배율 C 머리 옆)으로 대신, 장면은 기계 판정 없이 사람 화면(벽 아님).

**S2 한 장 세기 시험**: 묶음 01(정면 정본)을 원본에서 세기 0.65·0.8·0.9로 다시 칠함(시드 1, 문구 = v4 `restyle-jobs.json`의 01 문구 그대로) + 0.5 = v4 묶음 01. 세기마다 머리 둘레 Gram 점수 + Claude 눈 한 줄(원래 화소, `frozen/david-youth.png` 옆 — 곱슬머리·수염 없음·얼굴형이 남았나). 고르는 세기 = **문턱 안 그리고 Claude 눈 「같은 사람」인 가장 낮은 세기**. 없으면 `판정: 미채택 — 묶음에서 화풍과 정체성 양립 안 함`(벽).

**S3 묶음 관문**: 고른 세기로 25장 전부 다시 칠함(시드 = 그림 번호, 문구 = v4 그대로) → 문턱 안 ≥ 80%(머리 상자 못 잡은 장은 빼고 셈). 미달이면 다음 세기(0.65 → 0.8 → 0.9 중 한 단계 위) **한 번만**, 그래도 미달이면 `판정: 미채택 — 묶음 관문 미달`(벽).

**S4 학습**: v4 설정 그대로(`train/david-youth-v4.json` 복사 → v5, 300스텝, 데이터만 v5 묶음), 캡션 `davidy_bm, a man, <구도>` 그대로 → `lora/david-youth-v5.safetensors`. 다른 생성·학습과 겹침 금지.

**S5 장면**: 지금 기브아 `route_prompt` 1216×640 9스텝, 시드 8개(`LORA_V5_SCENE_SEEDS`) × 갈래 3 — **C** LoRA 없음 · **T** 다윗 cast 서술 앞에 `davidy_bm`만(LoRA 없음 — 낱말 하나 바뀐 「같은 화풍」 짝 = 소음 바닥) · **L** T 문구 + `david-youth-v5` 세기 1.0(사울엔 LoRA·트리거 없음). 토큰 > 512면 생성 안 함(벽).

## 채택 규칙

시드마다 d(L,C)·d(T,C) = 같은 시드 다윗 머리 둘레 Gram 2·6층 거리. **기계 「같은 화풍」 = 8시드 중 ≥ 6에서 d(L,C) ≤ max(d(T,C) 8시드)**(두 층 모두; 머리 못 잡은 시드는 불통과). 기계 「같은 화풍」이면 사람 화면, 아니면 `판정: 미채택(기계)`. S1이 `관문 아님`이면 기계 판정 없이 사람 화면.

사람 화면(기계 통과 때만): 폰용 비공개 Artifact, 한 화면 한 질문 — ① 시드 11 다윗 머리 둘레 C(위, 기준)·L(아래), 줄이지 않고 원래 화소 같은 배율(화소 적은 쪽이 작게) · 「같은 화풍 / 다른 화풍 / 모르겠음」 ② 전체 그림 C·L 같은 배율 같은 질문 · 화면마다 삼상 18:10-11 개역한글(18:11 굵게) · 맨 뒤 답 복사. **두 문항 모두 「같은 화풍」이면 화풍 통과** → 다음 작업 얼굴 판정·사울 확대.

## 결과

### S1 측정자 맞춰 보기 — `관문 아님`
- 맞음 C 9 · 틀림 12. **Gram 2층 AUC 0.889 · 6층 0.880**(문턱 0.9 미만) → `관문 아님`(`samples/lora-v5/metrics.json` `calib`).
- 가른 것은 C 하나: 445 C-s42 머리 둘레 점수 0.157(나머지 C 0.054~0.070 · 틀림 0.082~0.118). 크롭을 보니 머리 상자가 좁게(88×61) 잡혀 둘레에 **돌벽 결**이 크게 들어감 — 화풍이 아니라 크롭 내용 탓[추론]. 고정 절대로 결과 보고 규칙을 고치지 않음. 이 하나를 빼면 두 층 모두 C 8 전부가 틀림 12 전부보다 가까움(관찰 — 다음 측정자 작업 때 머리 둘레 크롭의 바탕 비율을 고정할 것).

### S2 한 장 세기 시험 — 양립하는 세기 없음
| 세기 | Gram 2 (참고) | Gram 6 (참고) | Claude 눈(원래 화소, 정본·C 머리 옆) |
|---|---|---|---|
| 0.5 (v4) | 0.206 | 0.398 | 같은 사람 · 다른 화풍 — 사실풍 음영 초상 |
| 0.65 | 0.206 | 0.395 | 같은 사람 · 다른 화풍 — 0.5와 거의 같은 그림 |
| 0.8 | 0.186 | 0.361 | 같은 사람 · 다른 화풍 — 연필 결은 늘었으나 얼굴 음영이 사실풍 |
| 0.9 | 0.162 | 0.311 | **다른 사람** — 어린아이 전신으로 바뀜, 화풍은 장면 쪽 |

- Gram 점수는 세기를 올릴수록 줄지만 0.9도 C 머리(≈0.06)·445 L(≈0.1)보다 멂(측정자가 관문 아니라 참고만).
- 0.8 → 0.9 사이가 **절벽**: 0.8까지는 초상 구도·얼굴이 그대로이고 화법만 조금, 0.9는 구도·나이·얼굴을 통째로 새로 그림. img2img 세기 하나로는 「화법만 바꾸고 얼굴은 두기」가 안 됨(화풍과 정체성을 같은 화소가 나름 — 계획의 가장 강한 반론 그대로).

- **판정: 미채택 — 묶음에서 화풍과 정체성 양립 안 함** (S2 벽 · S3 묶음 25장·S4 학습·S5 장면·S6 사람 화면 안 함 · v5 LoRA 없음)
