# PLATE-REST — 남은 판 경로 11장면 판 문구 바탕 + 요소 판정 + 고르기 (task 373)

370 회고 「칸을 저작하기 전에 판 묶음부터 판정한다」를 남은 판 경로 장면에 적용한다. 판 문구(`plate_whole_prompt`) 바탕 8장씩을 그리고, 요소 문항으로 **어느 장면의 어느 칸이 틀리는지**를 먼저 안다. 맞는 장면은 고르기로 끝낸다.

## 고정 절 (실행 전, 2026-10-20)

- 장면·편집 인물: `params.PLATE_REST_SCENES`(11) — 다윗 법궤 · 기브온 싸움 · 헤브론 유다 왕 · 예루살렘 정복 · 마하나임 피난 · 나단 언약 · 예루살렘 귀환 · 시글락 · 베들레헴 기름 부음 · 엔돌 신접한 여인 · 길보아 죽음. 아둘람 굴(사용자 미커밋 수정 중)·솔로몬 11장면(다음 과제)은 뺀다.
- 편집 인물: 편집 정체성 서술(`REF_EDIT_LIGHTNING_LOOK_IDENTITY`)이 있는 `saul`·`david`만 → 다윗 8장면은 `["david"]`, 나머지(기브온 · 베들레헴 소년 다윗 · 엔돌·길보아 노년 사울)는 빈 목록.
- 바탕: `plate_whole_prompt` × 8시드(`PLATE_REST_SEEDS` = `REF_EDIT_SEEDS` [11, 42, 7, 23, 5, 101, 202, 303]), 후보 편집 끔, 대조 묶음 없음. `run_night.py all --set plate-rest`. 칸 저작·문구 A/B·판 문구 수정 없음. 재생성 없음(한 회만).
- 실행자 눈 확인은 거르기 관문이 아니다(깨진 파일만). 사람만 고른다(ADR 260905-104910).

### 판정 페이지 (UAT 1)
- 368~370과 같은 요소 문항(명세 칸 경로 id, 한 화면 한 문항, 「틀린 그림 표시」): `moment` · `background[i]` · 무리(`crowds`, 둘 이상이면 `crowds[i]`) · 인물마다 `identity`(정본 초상이 있으면)·`pose`·`prop`·`facing` · `guard` → 마지막 고르기(`s<시드> 바탕` 또는 `없음`).
- 방향 문항은 370 문구(「{이름}이 누구와 마주 보는가(얼굴·상체)」). 이 장면들에는 한 장 모드 `gaze`가 없어 설명은 판 `facing` + 그 방향 앞쪽에 선 인물(`make_night_page.facing_q`, 테스트 `test_facing_without_gaze`).
- 화면 수: 문항 122 + 고르기 11 = **133화면**(계획 어림 88 — 인물 2~3명 장면이 다섯이라 많다). 사람 어림 메모 없음 약 29분 · 메모 많으면 약 55분.

### 고른 장 → 편집 → 확인 (UAT 2, ADR 261017-152627)
- 다윗 장면이고 고른 장의 `figures[i].identity`(다윗)가 틀렸을 때만 `run_night.py edit-pick <장면> --set plate-rest` → 확인 페이지(`plate-rest-confirm.html`). 맞으면 편집 없이 바탕 승인.
- 편집이 하나도 없으면 확인을 건너뛴다. 고른 장면은 `approved.final`(`path: night-pick`).

### 결론 규칙
- `판정: 고름 N/11`.
- 표: 장면 × 문항 틀린 시드 수, 고른 장, 확인 답.
- 「없음」 장면마다 8/8 또는 ≥ 3/8 칸과 그 칸의 부류(한 인물 자세 → 칸 저작 · 두 인물 접촉 → `relation` 칸 · 행동·지물 모양·무리 → 국소 편집 또는 명세 그릴링, PROMPTING 23·24, 371·372 결과)를 적어 다음 과제 후보로 남긴다.
- ADR `261017-152627`에 진행 한 줄(확인 장면 과반이 바탕인가 — 확인 장면이 0이면 그대로).

### 어림 시간
- 바탕 88 × 약 61초 ≈ 90분(무인) + 사람 약 30~55분 + 고른 장 편집 ≤ 8 × 약 9분.
