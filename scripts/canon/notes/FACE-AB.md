# 얼굴 유지 A/B 파일럿 (task 346) — S5 2×2 비교 기록

판정 페이지: `scripts/canon/samples/face-ab/index.html`(폰 390px, 6기준 체크박스 A/B 각각). 사람 판정은 아직 없음(기계 수치만).

출발 방식: e — 승인 그림을 출발점으로 얼굴만 바꾸는 쪽이 두 갈래 모두 기계 점수가 높고(e 0.168 vs f 0.144, A는 0.108 vs 0.074, B는 0.227 vs 0.214) 345에서 사람이 통과시킨 구도·뜻을 그대로 지킨다. 단 B의 (e)는 색조가 옅어지고(엔게디 굴이 밝아짐) 길갈 s23에 이음선이 생겨, 화풍 손실은 S6 사람 판정에서 봐야 한다(차이가 노이즈 범위라 약한 선택).

## 산출 (`scripts/canon/samples/face-ab/`)
- `<A|B>-<e|f>-<gilgal|engedi>-s<시드>.png` 16장(시드 42·23 — 345 시드 [11,42,7,23] 중 승인 시드 11·7을 뺐다) + 대조용 `approved-gilgal.png`(345 s7)·`approved-engedi.png`(345 s11) + `metrics.json`.
- (e): 345 승인 그림이 출발. (f): 같은 345 장면 프롬프트(`derive_scene --figures whole`)를 A는 Z-Image 시드 42·23 후보(345 `cand/`)에서, B는 klein이 새로 생성.
- A = 인물 1인 1LoRA(`~/.local/biblemap-imggen/lora/{saul,david}-v1.safetensors`)로 머리 타원 마스크만 인페인트(`gen_face_ab.py`: 머리 상자 2.6배 크롭→768→`ZImageInpaintPipeline` strength 0.85→마스크 안만 합성, 엔게디는 다윗 후 사울 순). 머리 상자는 OWLv2 열린어휘 검출(`face_ab_heads.py`) — claude -p VLM 좌표 읽기는 100~200px 어긋나 버렸다.
- B = klein 4B(`mflux-generate-flux2-edit`, q8, 4스텝, 1216×640). (e)는 [승인 그림, 정본…]을 넣고 「얼굴만 다시 그려라」, (f)는 [정본…]만 넣고 장면 프롬프트 + 「X는 이미지 n의 얼굴·머리·수염 그대로」. 길갈 사무엘은 새 정본이 없어 참조 없음.

## 참고 수치 (`metrics.json` — 판정 아님)
S2 자 = 크기 우대를 뺀 CLIP 마진 점수(정본 대비 − 다른 정본 평균), VLM = `check_face_judge.same_person`(정본 vs 머리 크롭). 인물 머리 단위 12개씩.

## 관찰
- B가 A보다 정본을 훨씬 잘 따른다(점수 2.4배, VLM 11/12 vs 3/12). A는 같은 LoRA도 시드마다 얼굴이 달라진다(길갈 s23은 백발 노인 사울) — 마스크 안 얼굴이 LoRA 학습 범위(근접·상반신 정면/사선)를 벗어나 작은 얼굴·옆얼굴에서 불안정하고 주변과 화풍 톤이 어긋난다(엔게디 옆얼굴이 녹색기).
- B는 화풍이 정본 연필 계열로 유지되나 (e)에서 색조가 옅어지고 길갈 s23은 세로 이음선이 생겼다. (f)는 구도가 345 승인본과 달라진다(길갈 사울이 가운데 가까이, 백성 많음).
- 점수 차는 인물·장면별 편차(0.1 안팎)가 크다 — 사람 6기준 판정이 최종이다.

## 실측 요약 (S1~S4)
- 정본(S1): Z-Image-Turbo 정면 머리 초상 768×768, 인물당 8장 → VLM 채점. 사울 시드 7(평균 9.0), 다윗 시드 11(9.25), 쌍 구별 9/10. 옛 SDXL 정본은 `frozen/retired-sdxl/`로 이동. 프롬프트 교훈: 'bare head'·'graying temples'는 정수리 대머리를 만든다 → 'hair covering the whole head down to the forehead, no hat'.
- 자/판정자 교정(S2): 임계(SPREAD_MAX 0.05, CORR_MAX 0.5, ACCEPT/REJECT 0.9)는 그대로. 열화 상한 `FACE_SCALE_DEGRADE_MAX_PX`=128 추가, (a)는 풀 평균 폭으로 변경, 검사 크기에서 32px 제외(사후 느슨화일 수 있음). 최종 사울 (a) 0.016·(b) 0.364, 다윗 (a) 0.004·(b) -0.499(경계). 판정자 다른 인물 기각 통과.
- LoRA(S3): 인물당 40장 생성 → CLIP 20 → VLM 12장, mflux 학습 300스텝(rank 16, 1e-4), 사울 2h05m·다윗 약 2h03m, 피크 30.7GB(32GB에 근접, 다른 프로세스 동시 금지), swap 0. 추론은 diffusers GGUF + load_lora_weights로 바로 됨. A는 「불가」 아님. 시트는 클로즈업·상반신뿐.
- klein(S4): 4B, mflux-generate-flux2-edit q8, 4스텝, 768², 정본 2장 참조로 36.6초, 피크 MLX 9.56GB. 첫 시도 성공.
