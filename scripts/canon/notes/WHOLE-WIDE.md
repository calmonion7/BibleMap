# WHOLE-WIDE — 판 경로 장면 5개 한 장 모드 칸 저작 + 판 문구 대조 (task 370)

369에서 채택된 한 장 모드 칸 저작을 판 경로 장면 5개(기브아 수금 · 놉 제사장 · 가드 아기스 · 야베스 구원 · 놉 학살)로 넓힌다. 369 회고대로 결론을 「고른 장 유무」가 아니라 **처치 칸 수치**로 낸다. 이 다섯 장면은 368에 없어 이전 바탕이 없으므로, 같은 8시드로 판 문구 바탕(`plate_whole_prompt`)을 대조 묶음으로 함께 만든다.

## 고정 절 (실행 전, 2026-10-19 18:14 KST)

- 장면·편집 인물: `params.WHOLE_WIDE_SCENES` — 기브아 수금(사울) · 놉 제사장(다윗) · 가드 아기스(다윗) · 야베스 구원(사울) · 놉 학살(사울). 편집 정체성 서술이 사울·다윗뿐이라 그 둘만 편집한다.

- 기계 거르기 없음. 사람만 고른다(ADR 260905-104910).

### 판정 규칙
- **처치 칸** = 한 장 모드 칸이 고치려는 문항: `moment` · `figures[i].pose` · `figures[i].facing`. 같은 사람·지물·배경·무리·가드는 처치 칸이 아니다.
- 칸 묶음: 368·369와 같은 요소 문항(명세 칸 경로 id, 한 화면 한 문항). 단 방향 문항은 이번 집합만 「{이름}이 누구와 마주 보는가(얼굴·상체)」로 묻고, 설명은 한 장 모드 `gaze`에서 만든다(인물 대상이면 「{대상}과 마주 봄 · 화면 {왼/오른}쪽을 향함」, 문구 객체면 그 `ko`). 마지막 화면은 고르기(`s<시드> 바탕` 또는 `없음`).
- 판 묶음: 처치 칸만, 같은 문구로, 칸 묶음 문항 바로 옆에 잇달아 묻는다. 두 묶음은 「묶음 가 · 묶음 나」로만 보이고, 어느 쪽이 판인지는 장면마다 `WHOLE_WIDE_SHUFFLE_SEED`로 섞어 metrics `plate.label`에만 남긴다. 고르기 없음.
- 고른 장면은 고른 바탕 한 장에만 편집 → 편집 확인(답 `편집본`/`바탕`) → 명세 `approved.final`(`path: night-pick`).
- 「없음」인 장면은 편집하지 않는다.

### 결론 규칙
- 장면 **풀림** = 칸 묶음의 처치 칸이 모두 ≤ 2/8.
- 장면 **저작 덕** = 풀림이고, 판 묶음에 ≥ 3/8인 처치 칸이 하나 이상 있었음.
- **채택** = 풀림 ≥ 4/5 이고 저작 덕 ≥ 1 → 남은 판 경로 장면으로 칸 저작을 넓힌다.
- **판으로 충분** = 풀림 ≥ 4/5 이지만 저작 덕 0 → 남은 판 경로 장면은 칸 저작 없이 판 문구 바탕으로 고르기만.
- **부분** = 풀림 2~3/5 → 안 풀린 장면의 ≥ 3/8 칸을 다른 수단(자세 가이드·국소 편집)으로. 문구 A/B 금지.
- **다른 길** = 풀림 ≤ 1/5.
- 결론 밖 기록: 고른 장 수(승인 기록), 판 ≤ 2 → 칸 ≥ 3로 나빠진 칸 목록, 편집 확인 결과, 사람 소요 분.
- ADR 절: 편집 확인 장면 과반이 「바탕」이면 ADR `261017-152627` 되돌리기 조건 2/2 충족 → 「편집을 기본 경로에서 빼는 결정을 다시 연다(다음 과제)」. 이 과제에서 ADR 결정을 뒤집지는 않고 진행 한 줄만 더한다. 확인 장면이 0이면 조건은 그대로 1/2.

### 어림 시간
