# 2026-08-03 — 출애굽 사건 공백 보강 1/3 — 출애굽기 전반(홍해 도하 포함) 7건 [일괄 승급 2026-08-03]

## 계획 대비 실제

- **계획대로**: 저작 장소 5곳·사건 7건·구절 베이킹·투어 정차지 24→31·스케치 7장·적재 검증 6슬라이스 그대로. 앵커 정합·등식 일치·양 뷰포트 UAT 전부 통과.
- **갈린 점 — 구절 검토가 7건 중 3건에서 "인용범위가 진술을 다 덮지 못함"을 잡았다.** 열 재앙은 범위(`7:14–11:10`)가 열째 재앙의 **예고**까지만 담고 집행(출 12:29–30)을 빠뜨렸는데 context는 "열 재앙을 내려"라고 완료형으로 서술했다. 이드로의 조언은 context 앞부분(십보라·두 아들 동행)이 범위 밖 18:1–6에만 있었다. 만나는 "광야 40년" 수치가 범위 밖 16:35에만 있었다.
- **갈린 점 — 투어 해설의 수치 오류 1건.** 같은 사건의 `context`는 "아홉 재앙에 이어 열째"로 정확히 구분했는데 투어 `note`만 "나일강 핏물부터 초태생의 죽음까지 **아홉** 재앙"이라 1~10번째 구간을 아홉이라 불렀다. **본문과 해설이 같은 파일에 없다는 이유로 서로 다른 사람이 쓴 것처럼 어긋났다.**

## 학습

- **다음에 다르게 할 것**
  - **구절 참조는 단일 연속 범위 하나로만 쓴다.** 리뷰어가 제안한 `7:14–11:10; 12:29–30` 세미콜론 분리안은 실효가 없다 — `generate_person_event_verses`가 같은 책의 **두 번째 세그먼트를 무조건 드롭**한다(사울·아브라함 기존 항목에서 실측 확인). 진술이 두 구간에 걸치면 둘을 포함하는 단일 연속 범위로 넓혀라. → CONTEXT.md 승급
  - **범위 확장이 억지 인용이 될 때는 진술에서 그 요소를 빼는 쪽을 택하라.** 만나의 "40년"은 근거 절(16:35)까지 넓히면 사이에 무관한 오멜 규례·안식일 규정(16:16–34)이 끼어 억지가 된다 — 수치를 삭제하는 편이 옳았다.
  - **`context`와 투어 `note`를 저작한 뒤 둘을 나란히 놓고 대조하라.** 수치·개수 표현이 어긋나는 사고가 실제로 났다. 파일이 달라도 같은 사건을 말하는 두 텍스트다.
  - **`books` 키를 아예 넣지 마라** — 스크립트가 `if "books" in ev: continue`로 멱등 스킵하므로 키가 존재하기만 해도 베이킹이 건너뛴다.
  - `enrich_place_coords`는 파일 전체를 MERGE하므로 "신규 N개" 로그가 실제 신규 건수가 아니다 — 개별 id 조회로 확인해야 한다.
- **특이사항**: `scripture-reviewer`를 워크플로우 안에 리뷰 단계로 넣은 것이 이 3건을 잡았다. 기계검증(개수·정렬·비어있지 않음)은 전부 PASS인 상태였다 — **"진술↔본문 정합"은 기계검증이 못 잡는 축이고, 이 아크에서 리뷰 단계의 존재가 값을 증명했다.**
