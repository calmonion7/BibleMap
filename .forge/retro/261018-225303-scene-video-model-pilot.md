# 2026-10-18 — 로컬 영상 모델 파일럿: 승인 장면 한 장 → 3초 영상, LTX-2.3 채택 (task 354)

## 계획 대비 실제
- 계획대로 된 것: 두 모델 모두 설치·생성 성공(8/8), 고정 절을 결과 전에 적음, 한 번에 하나 생성, 모델 이름 가린 폰 판정 페이지로 17문항 한 번에 답 받음(채택 LTX), 대표 클립 하나만 커밋. 완료 기준 4개 기준선 실패·실패·실패·통과 → 전부 통과.
- 어긋난 것:
  - **README 크기를 믿었다가 틀림.** `dgrauet/ltx-2.3-mlx-q4`는 「약 12GB」가 아니라 55.6GB(변압기 3벌·LoRA 2벌). 실제로 쓰는 파일은 모드가 정한다 — `--two-stage --low-ram`은 `transformer-dev` + `transformer-distilled-1.1`. 처음엔 distilled 변압기 둘 다 빼려다 `--low-ram`이 LoRA 융합 대신 그 파일로 바꿔 끼운다는 걸 소스에서 보고 하나만 뺐다. `--model`에 저장소 id를 주면 뺀 파일을 다시 받으려 해서 로컬 스냅숏 경로를 줬다.
  - **두 모델 기본 부정 문구가 우리 화풍을 밀어낸다.** Wan 「风格·作品·画作·画面」, LTX 「cartoonish rendering, stylized filters, grainy texture」. 결함 전용 공용 문구로 바꿈.
  - **Wan 단계 수는 계획에 없던 결정.** 원본 40단계 + CFG가 49.8 s/단계라 클립당 42분 — 감당 가능해서 공식값 유지. 4단계 Turbo LoRA는 라이선스 미표기라 안 씀. 미리 변환된 FastWan은 전용 샘플러가 필요해 mlx-video에 못 씀.
  - **다운로드가 실행 시간의 대부분.** 비로그인 HF 초당 3MB → 저장소 넷 동시 + xet 고성능 모드로 8MB. 받기 약 2시간 반, 생성 4시간 40분.
  - **판정 문항 둘(화풍·얼굴)이 갈라내지 못했다.** 두 모델 모두 16/16 통과. 채택을 가른 건 마지막 한 문항이고 이유는 안 물었다. 기계가 잡은 차이(LTX가 움직임 약 2배·더 빠름·메모리 절반, LTX 길갈 s42 한 프레임 걸러 끊김)는 문항에 없었다.
  - **깨짐 규칙의 거짓 양성.** 「중앙값 5배」는 한 프레임 걸러 차이가 0인 끊김 클립에서 중앙값이 낮아져 14프레임을 깨짐으로 셌다. 노이즈 기준(0.25)엔 한참 못 미침. 끊김은 짝·홀 차이 비(6.8 대 1.0~1.4)가 깔끔하게 가른다.
  - mp4·입력 그림은 계획의 `samples/video-pilot/`가 아니라 레포 밖에 둠(대량 커밋 안 함과 같은 뜻).

## 배운 것
- 다음에 다르게 할 것:
  - **새 모델 저장소는 받기 전에 파일 목록과 크기를 API로 본다**(`/api/models/<repo>/tree/main?recursive=true`). 그리고 쓸 모드가 실제로 여는 파일을 소스에서 확인한 뒤 `--include/--exclude`로 받는다. 받은 뒤엔 저장소 id 대신 로컬 경로를 넘긴다.
  - **새 생성 모델을 붙이면 기본 부정 문구부터 읽는다.** 사진·영화 쪽으로 학습된 기본값은 「회화·삽화·질감」을 결함으로 친다.
  - **HF 받기는 로그인하고, 저장소 여럿은 동시에 + `HF_XET_HIGH_PERFORMANCE=1`.** 받는 동안 생성은 돌리지 않는다(시간 측정이 오염됨 — 시험 클립 때 겹쳤다).
  - **처음 돌리는 모델을 먼저 돌린다.** 긴 배치 뒤에서 실패를 알면 몇 시간이 버려진다(이번엔 LTX를 앞에 둬서 첫 30분에 확인).
  - **채택 판정 페이지엔 「왜」를 하나 묻는다**(움직임 양·끊김·자연스러움 중). 축 문항이 모두 통과하면 채택 이유가 기록되지 않는다.
  - **영상 깨짐 검사엔 짝·홀 차이 비를 같이 둔다.** 중앙값 기준만으로는 끊김을 깨짐으로 오인하고, 반대로 끊김 자체는 사람 문항에서 빠진다.
  - 생성기 프로세스를 별도로 띄우고 `/usr/bin/time -l`의 「peak memory footprint」를 읽으면 MLX 통합 메모리도 잡힌다(RSS는 4~9GB로 작게 나옴).
