# 2026-10-21 — 성경 낱말 사전 3/3: 사람 판정 기록 · 판정: 보류(규칙 1·3) · 사전 verified_level 3

## 계획 대 실제
- 계획대로 된 것: 사람 답 기록(좌우 출처 단언) → 규칙 스크립트 `판정: 보류 (어긴 규칙 1, 3)` → 사전 verified_level 3항목(나룻배 L2·요단 L1·그적거림 L2, 모두 조건부) → 보류라 정본 명세 그대로 + 낱말 축별 다음 수단. 4화면 쉼 뺀 6.98분.
- 어긋남: 「둘 다 아님」 두 화면의 메모가 낱말이 아니라 명세를 짚음 — 요단 귀환 순간 범위(시므이 엎드림·가족 대기), 놉 칼 크기(2/3 자리 교체가 `huge`를 지움).

## 배운 점
- 낱말이 8/8 맞아도(요단) 순간 범위가 사람 읽기와 다르면 그림은 「둘 다 아님」이다 — 두 겹 판정의 1층(명세↔성경)이 낱말보다 먼저다(메모리 두 겹 판정과 같은 방향).
- 「둘 다 아님」에 메모를 받게 한 것(380 회고)이 원인 두 개를 바로 셀 수 있게 했다.
