- 이탈: **sortKey 교정 5건**이 "점검"에서 실제 교정으로 확대.

## 배움
- 다음에 다르게 할 것:
  - **연대 데이터의 정합은 사건을 추가할 때가 아니라 별도 감사로 봐야 한다.** 1부(task#233)에서 3건, 2부에서 5건의 sortKey 역전을 잡았는데 전부 **기존 데이터의 선재 결함**이었다 — 다윗 시글락이 길보아 전사 뒤로, 수금 연주가 골리앗 뒤로, 놉 학살이 놉 떡 앞으로 정렬돼 있었다. 신규 추가분을 넣으려다 발견됐을 뿐이라, 손대지 않은 구간에도 같은 결함이 남아 있다고 봐야 한다.
  - **연대계가 인물마다 다르면 전역 정렬이 조용히 무너진다.** 1부에서 이삭 출생(-2000)이 모리아 번제(-2055)·사라 장사(-2030)보다 뒤로 정렬되는 것을 발견했다 — 아브라함 연대계(부르심 -2091)와 이삭 연대계(출생 -2000)가 서로 다른 기준을 쓴다. 국소 수정으로는 못 고치고 이삭 연대계 전체 재정규화가 필요하다. **후속 감사 태스크 감**(신약 구간은 task#237·238이 date_corrections로 층간 정합을 완성했으나, 구약 인물 연대계는 미감사).
  - **정렬 역전은 Playwright 화면 검증이 잡는다.** 1부의 `abraham-departs-haran` 역전은 API 응답이 아니라 **모바일 화면 순서**에서 드러났다. 연대 데이터의 결함은 숫자를 훑는 것보다 렌더된 순서를 보는 쪽이 빠르다.
- 확인된 것(유지): 판정표를 `.forge/reports/`에 남기고 잔여 미커버 건수가 제외 목록과 정확히 일치하는지 대조하는 방식 — 누락과 의도적 제외를 구분해준다.
