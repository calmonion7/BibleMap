# 2026-09-03 — 삼상17 인물 판 셋 재작업(task 329): 시대 복식의 다윗 · 앵커 뗀 골리앗 · 무장 없는 종자 → v41

## 계획 vs 실제
- 계획대로: 코드 손잡이 셋(S3 앵커 제거·방패병 세로 0.53·`--plate-seeds`) · 방패병 판(sA s11, 문구 1종에서 통과) · 조립 v41 다섯 축 통과 · 문서(§0·§21·PROMPTING 14) · 커밋 · 봉인.
- 어긋난 곳:
  1. **다윗 투척 순간은 판 방식에서도 안 잡혔다** — 문구 3종 × 시드 4 = 12장 0 통과(끈이 손에서 시작 0·주머니 0). 계획이 미리 적어 둔 기각 규칙 「12장 → 멈추고 사람에게」가 작동해 사용자가 되돌림을 골랐다(ADR 154254). 계획의 DoD 「running mid-stride → 0」과 「§5 17:49 후반」은 폐기.
  2. **주머니는 물매와 한 그림에 못 넣었다** — 되돌림 문구 3종 × 시드 4 = 12장에서 「손의 물매」와 「주머니」 동시 출현 0(누적 24장). 두 번째 fork 벽에서 사용자가 주머니를 요구에서 뺐다. 체크리스트 S5 행이 두 번 완화됐다.
  3. **골리앗은 육안 통과가 기계 판정 낙제였다** — gA s42는 체크리스트 통과였지만 v40 조립 C4(잉크 비 3.37)가 낙제. 화풍 형용사(gB)는 효과 0, 색 낱말(gC)이 통과시켰다. 계획 슬라이스 4의 「스타일 블록 강화」 가정이 틀렸던 것.
  4. 시드 7은 부정어와 무관한 종이 테두리 prior — 판별 시드에서 뺐다.
- 발산 정도: **중간** — 목표(v39의 결함 넷 제거)는 셋(시대 복식·골리앗 둘로 보임·골리앗답지 않음)만 달성하고 하나(투척 동작)는 요구에서 빠졌다. 요구 변경은 전부 사람 결정으로 남았다.

## 배운 것
- **모델은 인물에 지물 하나만 붙인다** — 세 작업(325·327·329)에서 같은 벽. 요구를 쓸 때 인물당 지물 하나를 골라야 하고, 둘을 요구하는 문구는 어느 쪽을 앞에 두든 하나가 죽는다 → CONTEXT 용어로 승격.
- **기계 축이 재는 것을 먼저 읽어라** — C4는 「어두운 화소 비율」이라 화풍 형용사가 아니라 대상의 색 낱말이 움직인다(PROMPTING 14). 육안 체크리스트 통과 ≠ 회귀 가드 통과이므로 판 선택 전에 판 잉크를 미리 재면 조립 한 번(5분)을 아낀다.
- **미리 적어 둔 기각 규칙이 루프를 살렸다** — 「문구 3 × 시드 4 → 사람에게」가 없었으면 자동 드라이브가 어휘 변주로 캡을 태웠을 것. fork 벽 두 번이 모두 이 규칙에서 나왔고 둘 다 사람이 요구를 바꿔 풀었다.
- **시대·민족 낱말은 문장 맨 앞에** — 24장 전부 복식이 시대에 맞았다(v39의 셔츠·반바지·구두 재현 0).
- 다음에 다르게: ① 판 선택 단계에서 잉크 수치를 같이 찍어 후보를 고른다 ② 시드 후보군에서 7을 뺀다 ③ 골리앗 화풍(연필 결)은 문구 한계 — 공통 앵커/패치 레퍼런스는 별건으로 그릴링.
