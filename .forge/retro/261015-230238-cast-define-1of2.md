## 배움
- 다음엔 다르게:
  - **기존 값을 잠그는 과제에서는 검토 DoD를 「새로 쓴 것의 불일치 0 + 기존 결함은 이관 목록」으로 처음부터 나눠 쓴다.** 검토자에게 기존 필드도 보라고 하는 것 자체는 옳았다(진짜 결함 5건을 찾았다). 다만 DoD가 그것까지 0이기를 요구하면 잠금과 모순된다.
  - **적대적 검토 루프는 1회차에서 범위를 고정한다.** 2회차부터는 「1회차 불일치의 재판정」만 하고, 새 발견은 별도 목록으로 받는다. 이렇게 하면 회차별 수치가 수렴 여부를 보여 준다.
  - **카드 층 값 하나로 받칠 수 없는 인물은 2/2 그릴링에서 먼저 정한다.** 갈래는 정차지별 분기와 id 분할(saul/saul-old 방식) 둘이다. 351의 실패는 같은 생애 단계 안에서 같은 사람이 다르게 그려진 것이었다. 그러니 id 분할(단계마다 카드 한 값)이 351 요구와 덜 부딪힐 수 있다 — 판단은 fg-ask에서 한다.
  - **기억으로 쓴 인용은 원문과 갈린다.** 도엑 21:7 「에돔 사람 도엑이요」는 원문 「도엑이라 이름하는 에돔 사람이요」를 고쳐 쓴 것이다. 인용은 `verses.json`에서 복사하고, 이제 검사(c2)가 잡는다.
