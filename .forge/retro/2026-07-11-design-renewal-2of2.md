## Learnings

- Do differently next time:
  - **WebGL(지도) 화면의 헤드리스 시각 이상은 GPU 플래그 A/B를 최우선 1분 테스트로.** `chromium.launch(args=["--enable-gpu","--use-angle=metal"])` 비교가 앱/환경을 즉시 가른다 — 이번엔 앱 회귀로 단정하고 CSS 이분 탐색(색상 스킴→폰트→배경→토큰)으로 여러 빌드를 태운 뒤에야 도달했다. 트리거 조건도 특정함: 캔버스 위 불투명 오버레이가 유효 스타일을 얻으면 SwiftShader가 캔버스를 부분 페인트(그래서 토큰 정의 전엔 멀쩡해 보였음). → 메모리 승급.
  - **MapLibre 캔버스는 래스터+오버레이 공유** — 지도 톤 조정은 CSS filter가 아니라 래스터 레이어 paint(`raster-saturation` 등)로. 방향서가 CSS filter 값을 명시했지만 목업(img 태그)과 실앱(단일 캔버스)의 구조 차이를 계획 때 놓쳤다.
  - **외부 타일 서비스 채택 전 줌 피라미드 프로브** — 타일 크기 curl 프로브(z5~10)로 플레이스홀더 경계(z10+, 2521B 고정)를 확정하고 `maxzoom` 선언. 서비스 교체 계획에는 "지원 줌 범위 확인" 단계를 넣을 것.
  - 리뷰 에이전트 프롬프트에 **계획이 허용한 예외를 명시적으로 나열**할 것 — 이번 critical 1건은 계획된 M2 강등을 범위 이탈로 오탐(다만 그 검토 덕에 '경~' 중복을 발견 — 오탐도 시각 검수 단서로 유용했다).
- 확인된 것: 표기 중복은 데이터 파생 표기(yearLabel의 '경')와 UI 추가 표기를 겹칠 때 생긴다 — 강등·축소 작업은 기존 표기의 의미를 먼저 조사.
