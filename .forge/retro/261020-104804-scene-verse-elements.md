# 2026-10-20 — 구절 충실 명세 (task 375) — 14장면 구절 시각 요소 목록 + 검사, 성경 검토 3회 누락 0/14

## Plan vs actual
- What went as planned: S0 고정 → S1 검사기·테스트(빨강 → 초록) → S2 14장면 저작(data-author 4개 병렬, 파일 겹침 없음) → S3 검토 → S4 커밋. DoD 1~4 통과.
- Divergences:
  - 검사를 계획보다 강하게 했다: `quote`가 명세 `verses.quotes`뿐 아니라 **개역한글 본문(verses.json)**에도 있어야 하고, `en`이 `field` 칸 문자열 안에도 있어야 한다. 명세 인용만 보면 의역·지어낸 인용을 못 거른다.
  - DoD 3 grep 무늬(`prior에 없`)는 법궤의 「prior에 **불안정**해 … 대체」를 못 잡았다 — 계획 결정 4로 함께 지웠다.
  - 검토가 1회가 아니라 3회: 1차 14장면 지적 약 25건 → 고침 → 2차(실질/경미 나눔) 실질 5건 → 직접 고침 → 3차(5장면) 0.
  - 검토 지적으로 순간 범위를 3장면에서 넓혔다(기브온 2:13-14 · 놉 21:9 · 길보아 31:4 전반~중반) — 요소가 순간 밖 절의 동작을 끌어온 모순을 순간 쪽에서 풀었다.

## Learnings
- Do differently next time:
  - **기계 검사 통과 ≠ 구절 충실.** 저작 에이전트 4개가 모두 `check_scenes` ✅로 돌아왔는데 1차 성경 검토가 약 25건을 찾았다. 유형이 반복된다: ① 본문에 없는 세부를 구절 근거로 적음(손톱·뿔·성문 파괴·뒤로 물러섬·「몇」 명) ② 수를 바꿈(형제 일곱 → 셋) ③ 순간 다른 절의 동작을 실음(여인 외침 28:12, 2:14 제안, 「내게 주소서」) ④ 장소·대상 착오(길갈 vs 강가, 아기스 책망 대상). 다음 저작 지시에 이 넷을 미리 금지로 적는다.
  - **본문 밖 연출은 지우지 말고 「본문 밖 · 저작자 정함」으로 정직하게 표기**한다 — 그래야 검토가 연출(경미)과 모순(실질)을 가를 수 있다.
  - **검토는 처음부터 실질/경미를 나눠 받는다.** 1차에서 섞어 받자 수렴 기준이 흐렸고, 2차에서 나누자 바로 5건 → 0으로 수렴했다. 「누락」 = 빠진 보이는 요소 · 잘못된 제외 · 본문과 모순(수·장소·시점) · 순간과 다른 시점의 동작.
  - 요소가 순간 밖 절을 끌어오면 요소를 빼기 전에 **순간 범위를 넓히는 쪽**을 먼저 본다(사용자 「구절을 빼지 말라」에 가깝다).
  - 명세가 바뀌면 그림·판정 기하가 따라 낡는다(기브온 앉은 자세, 베들레헴·엔돌·정복 새 상자, `judge.gap_bands`) — 명세 과제의 notes 끝에 「재생성 필요 장면」 목록을 남기는 것을 기본으로.
  - fg-loop 운전: 서브에이전트를 기다리는 동안 `drive.md`를 내려 두고 결과가 오면 다시 세웠다(Stop 훅이 헛돌지 않게) — forge 쪽 개선 후보.
