# 2026-07-17 — 가계도 개편 2/3: 앵커+접힘·어머니 그룹·노드 위계 (task#196, 일괄 승급 2026-08-19)

## 계획 대비 실제
- 계획대로 된 것: family API 확장(slug·curated·role·lineage·mothers), 앵커+접힘 세그먼트, 어머니 그룹, 손주 축약, 노드 3계층. 커밋 5c282f8 배포 성공.
- 이탈: ① S2 완료 기준 "다윗 조상선 8행 이하" 미달(실측 18행) ② 절대배치 그리드 → DOM 플로우(flex-wrap)+실측 SVG 커넥터로 전면 교체 ③ lineage 정의 1차 구현(조상∩자손 교집합) 기각 후 재구현 ④ **테마 검증 1차 거짓 통과**.

## 배움
- 다음에 다르게 할 것:
  - **검증이 "통과"했다고 그 조건을 실제로 만들었다는 뜻은 아니다.** Playwright `color_scheme='light'`는 이 앱에 무효였다 — 앱 테마는 `prefers-color-scheme`이 아니라 `localStorage('biblemap-theme')` + `data-theme`이다. 초기 12조합 중 **light 6개는 실제로 다크를 찍고 있었고** 전부 PASS로 보고됐다. 검증 조건을 세팅했으면 **그 조건이 실제로 적용됐는지를 먼저 단언**해야 한다(여기선 `data-theme` 값 확인).
  - **정본 용어와 수치 기준이 충돌하면 정본을 지키고 수치는 미달로 기록한다.** "앵커(인장 보유)는 항상 노출"([[앵커-인물]])과 "8행 이하"가 충돌했을 때 앵커 규칙을 지켰다. 수치 기준은 계획 시점의 추정이었고, 1부에서 인장 15점이 다윗 직계에 밀집 추가되면서 전제가 깨졌다 — 앞 파트의 산출물이 뒤 파트의 완료 기준 전제를 바꿀 수 있다.
  - **줄바꿈·가변 폭·그룹 컨테이너는 절대배치와 양립 불가다.** 세 요구가 동시에 들어오면 절대배치 그리드를 수선하지 말고 DOM 플로우 + 렌더 후 실측 커넥터로 갈아탄다(ResizeObserver로 재측정). "기존 레이아웃을 유지하며 수선"이 오히려 비싸진다.
  - **그래프 관계의 교집합으로 계보를 정의하면 모계 우회까지 걸린다.** 조상∩자손 교집합은 압살롬→다말(딸)→마아가→아비야를 계보로 과잉 마킹했다. "예수에서 남계 사슬만 걷기 + 마리아 예외"로 재정의해야 마태1·눅3·창세기 계보가 정확히 재현된다.
- 확인된 것(유지): 성경이 기록하지 않은 것은 저작하지 않는다 — 다윗 21자녀 중 어머니 명시는 11명이 전부였고(대상 3:6-8이 나머지를 기록 안 함), DoD의 "전원 연결"은 11/21로 충족된 것으로 판정했다.
