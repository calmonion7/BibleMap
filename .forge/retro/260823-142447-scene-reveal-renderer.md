## Learnings

**다르게 할 것 — 외부 관행을 인용할 때는 전체 단계를 먼저 열거한다.**
이번 회고의 뿌리다. 「웹툰 파이프라인 순서」를 펜선 → 채색 → 식자로 적었고 그 셋은 **맞았다**.
그래서 아무도 못 잡았다 — 틀린 것을 적었다면 검토가 걸리지만, **옳은 것을 덜 적으면** 문서에 흔적이
없다. 다음에 관행·표준·타 도메인 파이프라인을 정본으로 인용할 때는 (a) 전체 단계 열거 (b) 따르는
구간 명시 (c) 따르지 않는 구간을 미결/비목표로 표시. → ADR `260823-142107`로 승급.

**다르게 할 것 — 증상별 미결을 새로 열기 전에 기존 미결과 원인을 대조한다.**
앞단계 결손은 이미 네 곳에 증상으로 있었다(task#304 S1 화풍 드리프트 · S2 얼굴 일관성 ·
S3 인물 레이어 · ADR `260822-111304` 다인물 「원리적」 제약). 넷을 각각의 축으로 다루면 넷을 각각
풀어야 하고, 하나의 결손으로 보면 앞단계를 세우는 것 하나다. **증상은 발견된 자리에 기록되고
원인은 어디에도 기록되지 않는다.** ADR `260822-111304`가 「원리적 제약」이라고 쓴 것이 실은
자산 결손이었다는 점이 특히 값비싼 오분류였다 — 「원리적」은 탐색을 멈추게 하는 단어다.

**다르게 할 것 — 위임 지시서를 쓰다가 계획의 수치를 「개선」하고 싶어지면 그 지점이 정본이다.**
정확도가 올라가는 방향의 변경이 가장 잡기 어렵다. 틀린 값은 검토가 잡지만 **더 정확한 틀린 값**은
정당해 보인다. 이번에 살아난 것은 적대적 리뷰가 같은 실행 안에 있었기 때문이고 그것은 규율이 아니라 운이다.
→ ADR `260822-220823` 부분 개정.

**다르게 할 것 — 산출 대조 완료기준에는 「무엇을 비교하는가」를 함께 적는다.**
스크린샷 전체 해시는 판정 대상 밖(카드 테두리·패딩)까지 재므로 서브픽셀 차이 하나가 기준을 실패로
만들고, 판정이 그 차이를 해명하는 데 소진된다. → ADR `260820-204317` 부분 개정.

**다르게 할 것 — 단계별 채택을 묻는 슬라이스는 판정 도구 제작을 스스로 포함해야 한다.**
①(현행)은 변경 전 코드가 필요해 실앱으로는 나란히 보여줄 수 없다. 계획의 S5는 「폰에서 ①②③을
보여 준다」고만 적었고 **무엇으로 보여줄지가 비어 있었다**. 이번엔 실행 뒤에 판정 페이지를 만들어
메웠지만(`.forge/scratch/task306/ladder.html`, 카드별 재생 — 폰에서 세 팔이 한 화면에 안 들어온다),
계획 단계에서 슬라이스로 잡혀 있어야 했다. 사다리·A/B 판정 슬라이스의 일반 규칙으로 삼는다.

**승급 안 함(구현 세부·다음 실행의 재료)**

- `getComputedStyle`은 CSS 시간 값을 **단위 정규화**해 돌려준다 — 스타일시트의 `500ms`가 `.5s`로
  나오고 인라인의 `9230ms`는 ms를 유지한다. 단순 `parseFloat`가 0.5를 500으로 읽어 파생값 전체가
  500ms씩 어긋난 채 「통과」로 보고될 뻔했다(`cssTimeMs()`로 고침).
- SVG `<image href>`가 404면 Chromium은 「아무것도 안 그리는」 게 아니라 **깨진 이미지 아이콘을
  뷰박스 전체로 늘려** 그리고, 그것이 마스크를 통과해 얼룩으로 번진다. 그레이스풀 강등에는
  `onError`가 필요하다.
- `<mask>` 안에서 Scene을 복제하면 `<Label>`도 복제돼 이름표 자리에 채색층이 **글자 모양으로** 샌다
  (`.scene-wash text { display: none }`). 같은 복제가 `render_scene.py`의 총선 집계도 197 → 394로
  이중집계한다 — 그 도구로 밀도를 재는 사람이 조용히 2배를 읽는다(`closest('.scene-wash')`로 제외).
- `visibility`는 **상속 속성**이므로 공유 키프레임에 넣으면 무관한 소비자(`.symbol-draw`·`.thread-draw`·
  `.intro-line`)의 상속 가림을 깬다 — 전용 `scene-draw` 키프레임을 신설한 이유.
- CSS 애니메이션 값은 cascade에서 **인라인 스타일보다 위**다. 그래서 `.scene-draw`가 `visibility`를
  몰기 시작하자 `render_scene.py`의 인라인 감선 필터가 조용히 죽었다(`!important`로 복구).
- **알파 채색층의 바이트 대가**: 12.7KB(RGB) → 50.2KB(RGBA q88). 연속 알파 램프를 그대로 구우면
  140KB까지 튀고, 8단계 양자화 + 투명 구간 RGB 평탄화 + `alpha_quality=60`으로 되찾는다.
  296장면 환산 약 14.8MB — 전면 확대 판단의 입력.
- 시드가 갈린다: 대응 지표 seed11 60.7% / seed21 52.9% / seed42 32.0%. 낮은 두 시드는 조건 입력에
  없는 가짜 캡션·액자를 지어냈다.
