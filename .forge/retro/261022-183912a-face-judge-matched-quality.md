## 배운 것
- 다음엔 다르게:
  - 사람이 「화질」을 말하면 화면 인코딩보다 **원본 머리 화소(상자 크기)부터** 잰다 — 120px 안팎이면 처음부터 얼굴 보정 단계를 계획에 넣는다(화면 손질 반복은 같은 판정 반복과 같다).
  - 얼굴 비교 화면은 「선명도(실측) + 화면 크기」를 둘 다 맞춘다 — 둘 중 하나만 맞추면 답이 기운다(v1 1/8 → v2 6/8·8/8).
  - 장면 대 장면 기준 그림은 **정본 얼굴을 가진 그림**으로 고른다(옛 승인 그림은 LoRA 전 얼굴이라 기준이 안 됨, 나이 다른 생애 단계도 금지).
  - LoRA 갈래는 화풍을 깬다(16/16) — 다음 시험은 「장면은 C, 얼굴 보정에만 V3 LoRA」.
  - 같은 프로세스에서 LoRA 있는/없는 생성을 섞지 않는다(없는 것 먼저 또는 따로).
