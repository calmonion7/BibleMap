# 2026-07-20 — 하나님 의존도 R1·R2 구약 26명 재정규화 (Part 2/3)

- What went as planned: 인물당 서브에이전트 26개(eco: sonnet 캡 + ECO 프리펜드) 병렬 저작. **허용 구절 팔레트**(세 출처 사전검증)를 각 에이전트에 제공 → 전원 `verse_sources_ok=true`, `validate_god_reliance.py` 위반 0(195항목), 구절 환각 0. 정의(ii) 계수식 불변(코드 무변경). NT 5명+adam 불변(구약 전용 범위 준수). S4 검증(validate+before/after 덤프+이상치 리뷰+api 재기동 UI)은 메인 세션(opus)이 결정론적 수행.
- 최종 변경 10명: 병합 3(abel 2→1·enoch 4→2·cain 5→4)·별건/은혜 추가 6(daniel+2·moses·joshua·samuel·job·solomon)·계기절 정정(cain). 15명은 이미 정분류로 **변경0 확인**. daniel·moses 표본적음 뱃지 소멸.
- Divergences: 에이전트가 **야곱 벧엘 언약을 독단-개입(분모)으로 재분류(88→75, 최대 이동)** → 회고에서 **오판으로 판정, 복원**(아래 학습 1).

## Learnings
- Do differently next time:
  - **[핵심] R2 판정에서 AUTHORING의 "인물 예시"를 그 인물의 모든 순간에 일괄 적용하지 말 것.** 에이전트가 AUTHORING §2의 "독단 중 붙드심(야곱·삼손 등)→독단-개입" 예시를 야곱의 **벧엘 언약**에 그대로 적용해 언약형(분자)→독단-개입(분모)으로 오분류. 사용자가 "성경 보면 답 나옴"으로 성경 대조를 지시 — **창세기 28:1-5**(이삭이 야곱을 축복·명하여 밧단아람으로 **보냄**, 그 축복에 아브라함 언약을 실음) + **28:13-15**(하나님이 언약을 직접 선언·수여)로 보면 하란행은 "혼자 도망(독단)"이 아니라 **순종적 파송**, 벧엘은 **언약 수령** = **언약형(분자)**. R2 판정은 **순간별 서사 문맥**이 심판이고, 애매하면 성경 본문 자체가 최종 근거. → AUTHORING §2에 명문화 완료.
  - **팔레트 기반 환각 방지 가드가 병렬 데이터 저작에서 유효.** 인물별 허용 구절 팔레트(기존 god_reliance + relations 하나님-phase + person_events rangeLabel 환산, 전부 정본 사전 사전검증)를 각 서브에이전트에 넘겨 "팔레트 밖 구절 사용 금지"를 강제 → 26명 전원 구절 환각 0. **Part 3·향후 모든 성경 데이터 스윕에 재사용**(스크립트 `palette.py` 패턴).
  - **변경0이 다수(15/26)인 것은 스윕이 무비판 통과가 아니라 데이터가 이미 정확했다는 신호.** 고위험 인물(요나 물고기·박넝쿨, 삼손 사자·결박, 다윗 밧세바·인구조사)이 **이미 분모로 정분류**임을 검증 — 부풀림 없음. 병합/추가는 소수 실제 오류에만.
  - **동일 사건 이중출처 병합**(아벨 창4:4+히11:4, 에녹 창5:22+히11:5+창5:24)은 R1 사건단위의 정당한 확장 — 창세기 서사와 히브리서 회고를 한 순간으로(%불변, 이중계수만 제거). 사용자 "병합이 맞음" 승인.
  - **[Part 3 대비]** 신약 5명 R2 경계: 예수(성자·순종 — 기존 골격 존중, 위반만 교정)·베드로(부인→회복 은혜)·바울(다메섹 부르심)·마리아(수태고지 언약형 수령). 야곱 교훈 적용 — **인물 일괄 판정 금지, 순간별로 "비반역 수령(ⓐ)인가 독단 중 붙드심(ⓑ)인가"**. 마지막에 32명 전체 랭킹 확정.
