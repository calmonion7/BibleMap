# 2026-10-20 — task 376 2/2: 후보 화면 사람 판정 → `판정: 보류`, 품질 천장은 명세(장면 묘사)였다

## 계획 대비 실제
- 계획대로: 판정 문장 기록(본 시드만 블라인드 라벨), 고정 절 세 규칙을 코드(`judge_learn.cand_rules`)로 판정 → 규칙 1·2 통과, 규칙 3 어김(블라인드 J1 잡기 66.7%·통과 72.6%) → 보류. 현황 페이지 갱신.
- 어긋남: 사람 시간 234분 중 209분이 두 장면(쉰 시간 포함 — 화면 타이머가 쉼을 못 가름). 판정 원문 `cand-verdict.txt`를 커밋함(이전 묶음은 미커밋 관례).

## 배운 점
- **기계 판정자는 명세 글에 충실했고, 명세가 성경보다 빈약했다 — 이것이 품질 천장이다.** 사람이 「없음」으로 본 4장면 모두 J1은 장면 뜻 「맞음」(블라인드 장면 뜻 잡기 1/7). 원인 대조:
  - 마하나임: 다윗과 「함께 있는 온 백성」(삼하 17:22, 17:27-29)이 명세 후보에도 없음 — 375 구절 요소는 순간 구절(17:24) 안에서만 뽑았고, 압살롬 군대를 「순간 밖」으로 뺀 것으로 끝남. J1 이유 「다윗이 성읍으로 향함 → 맞음」.
  - 요단 귀환: 유다 족속이 「원경에」만 있고 건너기를 돕는 행동이 명세에 없음(19:15·19:18 나룻배). J1 「원경에 무리가 있어 뜻은 통한다」.
  - 기브온: 명세가 순간을 2:13-14(마주 앉아 제안)로 잡고 2:15 열둘 대 열둘을 순간 밖으로 뺌, 두 지휘관 차림 칸 비어 있음 — 사람은 겨루기 장면을 기대(순간 고르기 자체가 사람과 어긋남).
  - 가드: 명세 「침을 흘린다」가 성경 「침을 수염에 흘리매」(21:13)보다 덜 세밀.
  - 베들레헴: 명세에 이새는 있으나 형제들 무리 칸 없음, 그림에서 누가 기름을 붓는지 모호 — J1은 「누가 사무엘인지 모호… 검은 옷을 사무엘로 보고 맞음」으로 **이상한 점을 보고도 너그럽게 넘김**.
  - 그림만의 결함은 놉(보자기가 칼날을 다 못 덮음) 하나 — J1 지물이 잡음.
- **기계 검사 통과 ≠ 구절 충실이 다시 확인됐다**(374·375 회고와 같은 함정). 375 `check_scenes` 「누락 0/14」는 요소 후보를 순간 구절로만 잡아, 주변 구절이 정하는 동행·도움·세부를 못 봄.
- 사용자 방향(2026-10-20 회고): ① **명세 판정자** — 장면 묘사가 성경에 근거하는지, 빠짐·축약·임의 순간 고르기를 면밀히 보고 세밀하게 표현하게 함. ② **그림 판정자** — 명세 글을 기준으로 이상한 점(누가 누구인지 모호, 역할이 바뀜, 명세 밖 이물)을 세밀하게 판별.
- 되돌림(8장 모두 장면 뜻 틀림)은 3/3 사람과 일치 — 지금 구조에서 가장 믿을 만한 부분.

## 다음엔 이렇게
