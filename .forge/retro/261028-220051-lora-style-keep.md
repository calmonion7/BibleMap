# 2026-10-28 — LoRA 화풍 지키기(단계 나눔 K3·K5 · 다시 칠하기 R) — 미채택, 원인은 학습 묶음의 초상 화법

## 계획 대비 실제
- 계획대로 된 것: 고정 절을 먼저 씀 → 시드 11로 5장 생성(콜백 단계 나눔 실측 L 1~9 · K5 1~5 · K3 1~3, 토큰 504/512) → 머리 둘레 → 8문항 화면 게시. DoD 1~6 통과.
- 어긋난 것:
  - **판정 화면을 네 번 고침(v1→v4)**. v1은 C 다윗 머리 상자를 OWLv2가 크게 잡아 배율이 다름(중앙값으로 통일) → 사람 「화질차이가 있어서 비교가 힘듬」 → v2 hf(라플라시안) 맞춤으로 갈래만 줄였다 키움 → 「기준이 화질이 높아」 → v3 머리당 화소 맞춤(갈래 79~88%로 줄임) → 「크기 말고 화소에 맞출순 있나? 화소가 적은 그림이 작아지는 방향」 → v4 줄이지 않고 원래 화소 같은 배율, 화면 폭 = 화소 수 비례.
  - **판정은 8문항 답 대신 사람 총평**(「기준이 화질이 더 좋아 보여」 → 「다 틀렸다고 결론이 날수 밖에」)으로 미채택. 갈래 사이 순위는 사람 데이터 없음.
  - 계획 밖으로 **화풍 자동 측정자**(`notes/STYLE-METRIC.md`, DINOv2 Gram 2·6층)를 맞춰 봄 — 같은 시드 C 대비로 사람 「틀림」 24/24, 대조 없는 AUC 0.95. 소음 바닥은 아직 모름.

## 배운 것
- 다음엔 다르게:
  - **화풍 비교 크롭은 처음부터 「줄이지 않고 원래 화소 같은 배율, 화소 적은 쪽이 작게」**. 라플라시안(hf)은 선 대비와 해상도를 한 숫자로 섞어, LoRA처럼 선이 진한 그림을 hf로 맞추면 해상도만 깎인다. OWLv2 머리 상자는 점수 1위가 갈래마다 머리 전체/얼굴로 엇갈리니 「후보 중 가장 큰 상자」로 통일.
  - **사람이 「화질이 다르다」고 하면 먼저 원래 화소(보간 없음)로 인물·바탕을 나눠 재 볼 것** — 바탕 잡결이 같고 인물만 다르면 화질이 아니라 화풍(LoRA가 배운 화법)이다. 이번엔 이걸 세 번 고친 뒤에야 확인함.
  - **LoRA 화풍 붕괴는 생성 쪽 묘수로 못 푼다** — 앞 3스텝만 걸어도 구도·화법이 정해지고, LoRA 없이 다시 칠하기 0.35도 못 지운다. 원인은 학습 묶음(`lora-sheet-v4`)의 사실풍 초상 화법. 다음 LoRA는 학습 전에 묶음 화풍을 자동 측정(Gram 2·6층, 승인 묶음 거리)으로 거를 것.
  - 화풍 기계 낌새는 장면 전체 hf 비가 아니라 DINOv2 앞쪽 층 Gram을 같은 시드 대조와 짝지어 볼 것(hf 비는 393 V2를 못 가름).
