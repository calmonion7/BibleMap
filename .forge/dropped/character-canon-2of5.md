# 1층 SVG 인물 정본 저작 — 조합표대로 실루엣을 그린다

## Goal / Non-goals

- **Goal**: 1/5이 확정한 명단·조합표대로 **인물별 머리 컴포넌트**를 `frontend/src/sketches/cast/`에
  저작한다. 다윗(`david.jsx`)은 기존이므로 나머지 전원.
- **Non-goals**: 이목구비 저작(정본은 **슬롯으로 비운다** — ADR `260823-190821` 1항 유지) ·
  얼굴 래스터(3/5·4/5) · 기존 장면에 정본 배선(B12 처분이 미결이므로 **장면 소스를 고치지 않는다**) ·
  지물/배경(별건).

## Source of truth

- ADR `260824-075708` ①(1층 = 실루엣) · ADR `260823-190821` 1항(머리 윤곽+머리카락+수염+머리쓰개,
  이목구비 슬롯) · 1/5의 `roster.json`(명단·조합) + `VOCAB.md`(어휘).
- **호출 규약 정본**: `frontend/src/sketches/cast/david.jsx` 헤더 주석 + `lib.jsx` 「정본 컴포넌트 규약」 절.
  좌표 계약(절대 anchor = `cx + 로컬x*scale`), **`stroke-width`는 `scale`로 곱하지 않는다**(검증기 `_SW`가
  `sw(<리터럴>)`만 읽어 구조 선이 조용히 미분류된다), 조건 분기 금지(전개기가 정적 파서다).
- **크기 하한**: 머리 반지름 **≥ 4단위** — 그보다 작으면 장면이 얹는 이목구비가 먹덩이가 된다
  (task#307 파일럿 실측, CONTEXT [[인물 정본]]). 실루엣은 **구조 선(≥2.0)**이 진다(얇은 선 1.1~1.4는
  격리하면 뭉치고 원경 ×0.45에서 소실).
- **회고 함정**: `.forge/retro/260823-221839-character-sheet-pilot.md` — ① 전개기가 `cx`/`cy`를
  **속성 이름 자리까지** 치환해 정본 머리 원이 B10·B11에서 통째로 사라진 선례(게이트가 초록으로
  거짓 통과) ② 문서 규칙(머리 지름 = 어깨 폭의 0.45~0.6배)과 승인된 실물(GoliathScene 비 1.6)이
  어긋나 있다 — **모순의 양쪽이 다 사람 판정을 통과한 상태로 공존**한다.

## Slices

### S1. 규약 재확인과 함정 감사
저작 착수 전에 `david.jsx`·`lib.jsx` 규약을 읽고, 위 회고 이탈 ①의 전개기 결함이 **현재도 남아 있는지**
`grep`으로 확인한다(ADR을 쓰는 것과 코드베이스가 지키는 것은 다른 사건 — task#305 회고).
- **완료기준**: 전개기 치환 경로의 현재 상태가 한 줄로 기록되고, 결함이 남아 있으면 **저작 전에** 고친다.

### S2. 인물 정본 저작 (병렬)
조합표대로 컴포넌트를 그린다. 인물별로 독립이므로 **병렬 저작이 실이득**이다(렌더·GPU와 달리 공유 자원
경합이 없다) — `line-artist` 역할로 팬아웃한다. 각 파일은 `david.jsx`와 같은 헤더 규약을 갖는다
(그리는 것 · 호출 규약 · 규격 · 별칭 선언).
- **완료기준**: `roster.json`의 모든 인물에 대응 파일이 존재하고, 각 파일이 **자기 별칭을 선언**하며,
  조합표의 5축이 헤더에 명시된다.

### S3. 기계 검증
저작물이 규약을 지키는지 전수 검사한다 — 머리 반지름 ≥ 4단위 · 실루엣이 구조 선(≥2.0) · `sw()` 리터럴 ·
조건 분기 0 · `roster.json`과 파일 집합 일치.
- **완료기준**: 검사 스크립트가 전수 PASS. **`--selftest` 대조군**은 각 경계를 하나씩만 위반하게 짠다
  (여러 경계에 동시에 걸리면 목표 경계를 증명하지 못한다 — ADR `260821-000937`).

### S4. 눈 — 사람이 볼 수 있게 찍는다
`#/cast`(`CastSheet.jsx`)에 전원을 게재하고 `render_scene.py --cast`로 촬영한다. 저작 에이전트는
자기 그림을 못 본다(ADR `260822-072153`).
- **완료기준**: 시트 PNG가 `.forge/reports/character-canon/`에 남고, 전원이 한 화면에서 **서로 다르게
  읽히는지** 육안 확인 결과가 기록된다(닮은 쌍이 있으면 조합표로 되돌린다 — 4/5의 게이트보다 싼 조기 검출).

## Definition of Done

1. `CHECK_STRICT=1 bash scripts/check.sh` 전항목 PASS.
2. `ls frontend/src/sketches/cast/*.jsx | wc -l` 가 `roster.json` 인물 수와 일치.
3. 규약 전수 검사 스크립트가 PASS하고 `--selftest`도 PASS.
4. `.forge/reports/character-canon/` 에 시트 PNG가 존재한다.
5. 각 정본 파일이 `roster.json`의 5축을 헤더에 명시하고, 그 값이 **파일과 JSON 사이에서 일치**함을
   스크립트가 대조한다(문서와 실물이 어긋나 공존한 선례를 막는다 — ADR `260823-221839`).

## 리스크

- **74명 규모라 파트 자체가 크다.** fg-run이 워크플로우로 팬아웃하되, **한 슬라이스가 여러 인물을
  묶어 실패하면 전체가 되돌아간다** — 인물 단위로 독립 커밋 가능하게 쪼갠다.
- **문서 규칙과 승인된 실물의 모순이 살아 있다**(회고 이탈 ②: 머리 지름 대 어깨 폭 비). 새 정본이
  어느 쪽을 따를지 **저작 전에** 정해야 하고, 정하지 않으면 74명에 모순이 전파된다.
- **`#/cast` 화면은 개발 전용 라우트다** — 사용자 노출 금지(ADR `260823-190821`). 배선 시 확인.
