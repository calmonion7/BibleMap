# 2층 동결 — 얼굴을 고르고 못 박고, 구별성 게이트를 통과시킨다

## Goal / Non-goals

- **Goal**: 3/5의 후보에서 인물별 얼굴 **하나를 골라 동결**하고, **쌍거리 임계를 실측으로 보정**해
  전원이 구별성 게이트를 통과하게 만든다. 이 파트가 끝나면 정본 2층이 완성된다.
- **Non-goals**: 생성 배선(5/5) · 장면 재생성 · D_conti 재측정(별건, ADR `260824-075708` 미결).

## Source of truth

- ADR `260824-075708` ②(구별성 2단: 조합표 + 쌍거리 게이트, **임계값은 보정해서 정한다**) ·
  ④(2회 이상 등장은 **사람이 고르고**, 1회 등장은 게이트가 자동 선택, **게이트는 전원 동일 적용**) ·
  ⑤(예수는 자동 선택에 넣지 않는다).
- ADR `260823-221839` — 게이트 없는 절대 수치를 그냥 적지 않는다. **임계값에는 근거 실측이 붙는다.**
- 1/5의 `validate_character_distinctness.py`(도구) · `roster.json`(명단·조합).
- **실측 근거**: CLIP 이미지 임베딩 1024차원, 쌍 유사도가 유의미하게 갈림(2026-08-24: 같은 장면·시드에
  마스크만 다른 두 장 0.917 ↔ 얼굴 크롭 vs 장면 0.63). **얼굴 크롭끼리의 분포는 아직 안 쟀다** —
  전부 사람 얼굴이라 유사도 대역이 위로 밀릴 것이므로 **임계를 여기서 실측 분포로 잡는다.**

## Slices

### S1. 사람 선택 (2회 이상 등장 + 예수)
3/5의 대조표를 보고 인물별로 하나를 고른다. 선택은 **근거와 함께** 기록한다(왜 이 후보가 이 인물인가 —
조합표 5축과 맞는가).
- **완료기준**: 대상 인물 전원에 선택이 기록되고, 선택 파일이 `frozen/<slug>.png` 로 복사된다.
  선택 근거가 `frozen/SELECTION.md` 에 인물별 한 줄로 남는다.

### S2. 임계 보정
동결 후보 전수의 쌍 유사도 분포를 재고, **「같은 인물의 다른 후보」와 「다른 인물」이 갈리는 지점**을
찾아 임계를 정한다. 임계는 설정 파일에 **분포 근거와 함께** 적는다.
- **완료기준**: 임계값이 파일에 적히고, **그 값을 만족하는/위반하는 실존 쌍이 각각 예시로 함께 적힌다**
  (ADR `260823-221839`). 분포 히스토그램이 `.forge/reports/character-canon/`에 남는다.

### S3. 자동 선택 (1회 등장 인물)
남은 인물은 「이미 동결된 집합에서 가장 안 닮은 후보」를 게이트가 고른다.
- **완료기준**: 자동 선택분이 `frozen/`에 채워지고, 각 선택이 **어떤 유사도 값으로 뽑혔는지** 기록된다.

### S4. 전원 게이트 통과
`validate_character_distinctness.py`를 전원에 걸어 임계 초과 쌍을 없앤다. 초과 쌍이 남으면 **닮은 쪽을
재생성**한다(3/5의 생성 경로 재사용). 조합표 중복 0도 같은 스크립트가 재확인한다.
- **완료기준**: 게이트가 전수 PASS. **재생성이 몇 회 필요했는지 기록**한다 — 그 수가 조합표의 품질 지표다.

## Definition of Done

1. `CHECK_STRICT=1 bash scripts/check.sh` 전항목 PASS.
2. `ls .forge/reports/character-canon/frozen/*.png | wc -l` 가 `roster.json` 인물 수와 일치.
3. `python3 backend/scripts/validate_character_distinctness.py` 가 전수 PASS(임계 초과 쌍 0, 조합 중복 0).
4. 임계값이 설정 파일에 있고 **분포 근거 + 통과/위반 실존 쌍**이 함께 적혀 있다.
5. `frozen/SELECTION.md` 가 인물별로 「사람 선택인가 자동 선택인가」와 근거를 담는다.

## 리스크

- **임계를 못 정할 수 있다.** 얼굴 크롭끼리 유사도가 좁게 뭉치면 「다른 인물」과 「같은 인물 다른 후보」가
  안 갈린다. 그러면 **CLIP 임베딩이 이 판정에 부적합**하다는 뜻이고, 임계를 억지로 잡는 대신 **음성 결과로
  기록**하고 사람 대조표 판정으로 되돌린다(task#305 이탈 5의 선례 — 음성 결과를 실패로 취급하지 않는다).
- **재생성 루프가 수렴 안 할 수 있다.** 조합표가 실제로 구별을 못 만들고 있다는 신호다 — 무한히 돌리지
  말고 **2회 실패하면 1/5의 조합표로 되돌린다.**
- **예수 선택은 신학적 판단이 섞인다.** ADR-0025의 절제 조항을 선택 근거에 명시적으로 적는다.
