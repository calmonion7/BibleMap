# 타임라인을 "책 연도 배치"에서 "사건-근거(연도→사건→권→구절)" 모델로 전환

직전 작업(2026-06-15 timeline-scripture-book-markers)은 66권을 (추정)연도로 타임라인에 단독 마커로 흩어 배치했으나, 사용자가 실제로 원한 것은 "각 사건의 성경적 근거"였다 — **연도 → 사건 → 성경권 → 성경구절** 순으로 그 사건이 어디에 기록되어 있는지를 드릴다운하는 것. 그래서 타임라인을 **사건 중심**으로 재편한다: 각 사건에 그 사건을 기록한 권(`CONTAINS_BOOK`)을 근거 칩으로 붙이고, 권→구절(theographic `verses` 해석, 인용 범위 + getbible 한국어 본문)까지 내려간다. 한 사건을 여러 권이 기록할 수 있어(공관복음 평행) 권은 목록으로 제공하고 정경순 첫 권을 디폴트로 연다.

## Considered Options

- **(채택) 사건-근거 모델** — 사건에 `CONTAINS_BOOK` 권을 칩으로 붙이고 구절까지 드릴다운. 사용자가 명시한 데이터 흐름과 일치, "row 쌓지 말고 뭉쳐서"도 자동 충족(책이 더 이상 독립 행이 아님).
- (반려) 책 연도 단독 마커 유지 — 66권을 (추정)연도에 흩어 배치. 행이 쌓여 지저분하고, 추정연도는 권위가 낮으며, "사건의 근거"라는 의도를 표현하지 못함.
- (반려) 시대 구획별 묶음 / 단일 통합 묶음 — "년도 옆에 사건의 근거"라는 사용자 의도와 어긋남.

## Consequences

- **책은 정확히 한 경로로만 등장한다.** `startYear` 있는 35권(= `CONTAINS_BOOK` 사건 연결됨)은 사건 근거 칩으로, `startYear` 없는 31권(서신서·시편·잠언 등, `yearApprox=true`)은 기존 추정연도 단독 마커로 유지된다. 두 집합은 겹치지 않아(startYear 유무가 곧 사건 유무) 같은 책이 칩과 마커로 중복 등장하지 않는다. 결과적으로 단독 책 행은 66 → 31로 줄어(클러터의 주범인 고빈도 사건책 35권이 칩으로 빠짐) "row 쌓지 말고 뭉쳐서"와 "31권 제외하지마"를 동시에 만족한다.
- **`/books` 엔드포인트 + `data/book_years_approx/` 추정연도 오버레이(직전 작업 산출물)는 31권 마커 표시에 계속 사용된다**(고아 아님). 단 타임라인은 `yearApprox=true`인 책만 단독 마커로 그리고, 나머지(35권)는 마커 대신 사건 칩으로 그린다.
- **31권(사건 없는 책)은 Part 2의 "구절 근거" 대상이 아니다.** 연결된 사건이 없어 사건별 구절을 가질 수 없으므로, 클릭 시 기존 Book 개요 패널을 그대로 연다. 구절 드릴다운은 사건 있는 35권에만 적용된다.
- 작업이 커서 2개 파트로 분할: Part 1(연도→사건→권, 권 클릭 시 임시로 기존 Book 개요 패널), Part 2(권→구절 본문). 각 파트는 독립 배포·검증·봉인된다.
