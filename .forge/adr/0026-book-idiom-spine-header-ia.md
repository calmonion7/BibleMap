# 책 펼침 디자인 언어 + 책등 전역 헤더 IA

"성경책에 들어온 느낌"을 **대문 자체를 펼쳐진 책(채식필사본 목차 면)으로 재해석**해 구현한다 — 별도 표지 스플래시는 기각(콘텐츠 앞 클릭/대기 추가 + 반복 방문 시 성가심; 모션 개편의 "고빈도 반복 재생 금지" 원칙과 충돌). 책 펼침 입장 모션은 세션 1회만 재생한다.

IA는 **책등(spine) 전역 헤더 + 책갈피 리본 3부(인물·성경책·투어)**를 신설한다: 기존에 대문 본문 버튼으로만 진입 가능했던 책 둘러보기·투어를 전역 리본으로 승격하고, 테마 토글도 대문 전용에서 전역 헤더로 승격한다. 리본은 기존 내비 콜백을 호출할 뿐 스테이지 상태 머신·해시 URL 체계(ADR-0009/0010)는 무변경 — IA의 겉모습만 바꾸고 뼈대는 재사용한다. 비용: 전 화면(지도 포함)에서 얇은 헤더(~40px)만큼 세로 공간을 상시 소모하는 것을 수용했다.

테마: 라이트=양피지 필사본(크림 지면·잉크 선·금박), 다크=밤의 서재/가죽 장정(짙은 지면·금박 선화) — 같은 책 관용구를 CSS 변수 두 벌로 표현한다. 기본 테마를 라이트로 뒤집는 안은 기각(ADR-0013/0020 유지).
